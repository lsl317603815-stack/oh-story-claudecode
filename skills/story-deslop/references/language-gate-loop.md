# 中文正文语言验收 Gate

## 唯一主链路

```text
正文写作者完成本章初稿
        ↓
运行 language_gate.js
        ↓
发现中英文混杂？──是──→ 连同行号、原片段、所在行退回正文写作者
        │                              ↓
        │                         修改原句或原段
        │                              ↓
        └──────────────────────────重新运行 Gate
        ↓ 否
运行去 AI 味与退化检查
        ↓
追踪提交、交付本章或开始下一章
```

## 强制规则

1. Gate 只判定和报告，不自动翻译，不自动删除，不自动写白名单；会读取正文路径向上最近的 `.deslop-whitelist` 并仅精确豁免其非注释条目。白名单条目必须来自用户对“逐字保留”的单独确认，不得由模型自行追加。
2. 任一发现均为 `blocking`。返回码不为零时，本章不得验收，不得提交追踪，不得写下一章。
3. 检查报告必须交回产生该正文的写作者，由其结合上下文改写；不得交给脚本做逐词替换。
4. 修改后必须重新运行 Gate，直到返回码为零。
5. 英文、缩写、型号和剧情代号不得由模型自行豁免。URL、邮箱、代码、路径和文件名只有在明确属于非叙事结构时才机械保护；技术报告和配置文件应由外层流程排除。HTML 标签、注释和实体不得进入交付正文。
6. 原有 `check-degeneration.js` 与 hooks 保留为第二道兜底，但不能替代本 Gate 的本章验收闭环。

## 命令

```bash
node skills/story-deslop/scripts/language_gate.js "正文/第001章.md"
```

需要结构化退回单时：

```bash
node skills/story-deslop/scripts/language_gate.js --json "正文/第001章.md"
```
