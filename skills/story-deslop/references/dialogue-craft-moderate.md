# 适度对白技巧

## 目标

对白技巧服务清晰度、人物、冲突和场景变化，不追求零标签，也不追求句句有潜台词。优先级固定为：

```text
读者能分清谁在说话
→ 对话符合人物和关系
→ 对话推动当前场景
→ 关键位置加入潜台词
→ 技巧尽量不被读者察觉
```

## 写前轻量对白卡

只在对白承担重要剧情功能时生成内部卡片，不要求落盘，也不逐句规划。结构遵循 [对白卡 schema](dialogue-scene-card.schema.json)，至少明确：

- 场景目的。
- 每个参与者想从对方那里得到什么。
- 每个参与者不能或不愿直说什么。
- 冲突中的策略和关键转折。
- 每个主要人物两到三个可执行的语言差异。
- 多人场景中容易混淆说话人的位置。

## 四种表达方式

1. 双人轮流且顺序明确时，允许直接写无标签对白。
2. 说话人可能混淆、又没有值得写的动作时，使用简单的“说/问”。
3. 动作还能传递意图、情绪、权力变化、物件状态或下一步行动时，用动作承接对白。
4. 强烈情绪不适合直接说出时，使用沉默、反应、内心或叙述。

简单“说/问”不是错误。禁止为了避开它们机械替换成“沉声道、冷声道、缓缓说道”。

## 标签决策

```text
不标注时读者能否分清？
├─ 能：不加标签
└─ 不能：是否有独立叙事价值的动作？
   ├─ 有：用动作承接
   └─ 没有：使用简单“说/问”
```

三人以上场景在人物首次开口、新人物进入、沉默数轮后重新加入、轮次被打破、较长叙述之后重新锚定。每位新说话人另起一段，人物动作与其对白保持在同一段。

## 有效动作测试

删除动作后，如果人物意图、情绪、权力关系、场景状态、关键物件、冲突压力和下一步行动都没有损失，该动作大概率只是填充。点头、喝水、抬眼、握拳、咬牙和叹气不能仅为替换标签而出现。

## 人物声线

每个主要人物只选择两到三个有效维度：

- 句长与节奏。
- 表达直接度。
- 关注点和职业词汇。
- 回避、试探或施压方式。
- 压力下的语言变化。
- 对不同关系对象的说话差异。

口头禅、方言和奇特比喻应少量使用，不能把人物变成标签集合。删掉人物名后能否大致分辨主要人物，可作为训练和审查方法，但不是最终正文必须零标签的要求。

## 潜台词剂量

潜台词适用于不敢直说、撒谎、试探、维护体面、隐藏立场和权力变化。普通事实、时间、地点、证据及操作步骤应清楚表达，不能全部写成谜语。允许普通连接句存在，不要求每句同时完成多项任务。

## 回修顺序

```text
先检查交谈目的
→ 再检查人物策略与潜台词
→ 再检查人物声线
→ 再检查沉默、打断和动作价值
→ 最后检查说话人归属
```

禁止只替换标签词，也禁止为了降低检测数字重写整段正常对白。

## 双层验收

机械检测负责定位连续同构归属、重复动作候选、多人场景锚定风险和跨章漂移。标签密度、动词集中度和基线偏移只是 `advisory`，不得单独阻断。

语义审查负责判断人物语言是否可互换、对白是否只在朗读剧情、动作是否有独立价值、潜台词是否过密、技巧是否显眼。以下情况可以退回：

- 连续逐句报幕，明显影响阅读。
- 大量空动作替代“说/问”。
- 多人场景无法辨认说话人。
- 主要人物语言基本可以互换。
- 对白只让角色互相朗读双方已知信息。
- 人物句句像金句、隐语或作者代言。
