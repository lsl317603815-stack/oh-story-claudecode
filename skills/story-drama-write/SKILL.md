# story-drama-write：短剧剧本写作（立项 → 分集纲 → 单集全稿）

你在这里写的是**能拍的剧本**，不是小说。跟长篇/短篇小说 skill 的根本差别：短剧是**对白驱动**——画面的事必须说出来，观众光听声音也要跟得上；内心戏没有落脚点，必须翻译成镜头拍得到的动作。

本 skill 不需要先有小说。**从一句想法直接开剧本**是它的常规入口；有原著要改编时按 `references/craft/adaptation-sourcing.md` 的回采纪律走。

## 铁律（违反即不合格）

1. **立项与分集纲只能采访拍板。** 世界观、项目大纲、角色卡、分集纲一律**不许一次性生成**——按 `references/drama-protocols.md` 逐项采访，作者点头才算数。**不确认不落盘**：采访没走完，目标文件一个字不写。作者已有成稿或明确说「这段照抄别问」时，照记入账，不重复采访。
2. **构思案锁版前不写全稿。** 单集剧本动笔的前提是本集构思案已经作者**锁版**（状态 LOCKED）。没有构思案就先采构思案，不许「边写边想」。
3. **画幅是立项必答项。** `9:16` 竖屏或 `16:9` 横屏，独立一题问，不许默认、不许委托。拍板后写进 `项目档案/世界观.md` 的 `画幅` 字段；此后每集剧本 frontmatter 的 `aspect_ratio` 必须等于它。它是写法开关不是标注——竖屏走特写/快剪/单主体，横屏才容得下中景与群像调度。
4. **正文格式照 `references/剧本格式规范.md` 落字**，一行式场头、`△` 动作行、`角色名：台词`。#镜号/机位/运镜/景别不写进剧本。
5. **发明机制检**：剧本长出构思案与世界观都没有的规则、数值、道具功能 → 撤掉，回设定找正解，不替它找理由。「是既有口径的某某形态」这种归类句不是出处；指不出设定原文哪一句，就是发明。作者明令新增的不算。
6. **作者亲写的对白逐字保留**，只补 `△` 动作与错别字，禁「优化」重写。

## 目录结构

```
剧本/{项目名}/
├── 项目档案/  世界观.md · 项目大纲.md · 分集表.md(固定集数) 或 集纲.md(滚动) · 前情提要.md
├── 角色总库/  CHAR_{名}.md · 人物索引.md
├── 场景总库/  SCENE_{名}.md
├── 采访/      {模式}_{目标}.md（决策账本）
└── 剧集/E{NNN}/  E{NNN}_剧情构思案.md · E{NNN}_剧本_v{N}.md
```

## 流程

### Step 1 · 认位置
读 `剧本/{项目名}/` 现状，判断缺哪一层，从最上面缺的那层起。已有的层**校验复用不重造**。项目不存在就先立项。

| 用户说 | 从哪起 |
|---|---|
| 我要写个短剧 / 开个新剧本 / 立项 | 立项采访（含画幅） |
| 加角色 / 改人设 | 角色采访 |
| 排分集 / 后面几集怎么走 | 分集纲采访 |
| 构思第 N 集 / 下一集写什么 | 单集构思案采访 |
| 写第 N 集 / 出全稿 | 构思案已锁→全稿；未锁→先采构思案 |

### Step 2 · 采访（立项 / 角色 / 分集纲 / 构思案）
按 `references/drama-protocols.md` 对应模式走。采访纪律：

- **先问根**：第一题永远是「从哪个根开始」，别一上来甩十几项清单。
- **一次一题**，带 2–4 个候选，推荐项放第一并写**后果**（「选这个，第 5 集的钩就要改」比「更有张力」有用）；至少一个把假设倒过来的反方向候选。
- **提案先行**：分集纲和构思案这种层级，先摆完整设计提案再对开着的决定出题——别让作者对没见过的设计选收尾帧。
- **整段输入拆解入账**：作者甩一大段设定时，原话逐字抄进采访记录，拆成编号的原子决定，逐条找冲突，划掉它答掉的待定项，**只追问缺口**。
- **冲突当场亮**，不替作者消化；新决定推翻旧决定时回去改旧行（`~~删除线~~ → 改为 X`），不只追加。
- **粒度不越层**：立项不问「这一场谁先开口」，分集纲不写具体台词——那是构思案和全稿的事。碰到就记一行「留下层」走人。
- **「你定」要记账**，标 `[作者委托]`，终审时列出来让作者最后扫一眼。
- 追问 2–4 轮即停；作者说「就这样」立即停。

采访记录落 `剧本/{项目名}/采访/{模式}_{目标}.md`，格式：开始日期/状态（进行中·待终审·已落盘）、依据文件、已拍板表、待定清单、冲突登记。

### Step 3 · 终审与落盘
1. 列 `[作者委托]` 项一题确认（没有就说「无委托项」）。
2. 分集纲跑 drama-protocols.md 的硬门（爽点递增、钩型 3 集不重复、角色 ID ∈ 索引）。
3. 给**落盘摘要**：列出将写的每个文件和它承载的决定。最后一题「按这个落盘？」——候选：落盘 / 再改某项 / 先不落盘只留记录。
4. 落盘时**只写采访记录里有的决定**，不夹带候选说明里的话和自己的推论；推论要写就标「（推论，待确认）」。文件头写「由 采访/{记录名} 渲染」。
5. 采访记录状态改「已落盘」，末尾写 `产物：{路径}`。

### Step 4 · 写全稿（构思案已锁才进）
岗位说明书 `references/layers/L5_单集剧本.md`；落对白执行总纲 `references/craft/dialogue-protocol.md`（落字前找成对样本、落字中点名三吸引子、落字后回译测试与废话检验）。必读盘不靠记忆：已锁构思案、出场角色 CHAR 卡与声音卡、前情提要、世界观（**含画幅**）。

写完按 `references/剧本格式规范.md` 第五节**落稿自查**逐条过（场序连续、出场人物与发声主体 ∈ 人物索引、`aspect_ratio` 等于立项画幅、frontmatter 齐全、无镜号机位）。本包不带 `drama_core` 机审，这些条目自己数自己核，**不许写「机审通过」**。

出稿后过 `references/craft/scene-audit.md` 的剧本医生四问（因果链是「因为」不是「然后」、每场有价值转变、删场测试、七维评分）。

### Step 5 · 锁版与回写
作者审过才算锁版（机器只保结构；憋点爽点钩是否落到位、台词味道、承接顺不顺＝人审）。锁版后：
- 剧本 frontmatter：`status: locked` ＋ `locked_at` ＋ `ending_state` / `continuity_from` ＋ `revision[]` 追一行。
- 更新 `项目档案/前情提要.md`（本集摘要＋尾钩＋下集承接口＋关系/服装/世界状态变化）。
- 滚动项目：本集已锁事实回写 `项目档案/集纲.md` 摘要区。

## 岗位说明书与 craft 方法论库

每一层动笔前，先读该层的**岗位说明书**（写什么、落哪、输出什么字段），再按它加载 craft：

| 层 | 岗位说明书 | craft 加载 |
|---|---|---|
| 立项世界观 | `references/layers/L1_世界观.md` | `references/craft/genre-guide.md`（13 题材定义＋叠加公式） |
| 角色卡（含反派） | `references/layers/L2_人物.md` | `references/craft/villain-design.md`（四层体系＋三问＋伏笔锚点） |
| 项目大纲 | `references/layers/L3_大纲.md` | `references/craft/rhythm-curve.md` ＋ `references/craft/satisfaction-matrix.md`（四阶段波形＋5 爽点分型） |
| 分集纲 | `references/layers/L4_分集.md` | `references/craft/hook-design.md` ＋ `references/craft/satisfaction-matrix.md`（5 钩型＋强度递增） |
| 单集全稿 | `references/layers/L5_单集剧本.md` | `references/craft/dialogue-protocol.md`（总纲）＋ `references/craft/dialogue-action.md`（说什么）＋ `references/craft/dialogue-naturalism.md`（怎么说像真人·七宗罪 linter）＋ `references/craft/rhythm-curve.md` ＋ `references/craft/hook-design.md`；**首集**另读 `references/craft/opening-rules.md` |
| 出稿后诊断 | — | `references/craft/scene-audit.md` |
| 改编项目 | — | `references/craft/adaptation-sourcing.md`（事件锚点检索＋知情状态对照＋登记不等于兑现） |

craft 共 11 篇、题材无关，索引见 `references/craft/README.md`。

craft 的实证语料库（124 张爆款拉片卡/结构卡）**不随本包分发**，在源库；文中 `card_NNN` / `scard_NNN` 引用按此理解，不要谎称读过卡。

## 停止条件

- 同一集构思案连改 3 轮方向仍不收敛 → 停，回采访逐轮钉分叉，不再盲写。
- 前情互相矛盾（集纲 vs 已锁剧本 vs 世界观）→ **以已锁剧本为母本**，报作者裁决，不擅自调和。
- 采访中作者长时间不答 → 保存采访记录（状态「进行中」）等下次续采，**不替作者拍板往下写**。

## 不做的事

- 不替作者写「你应该想写的东西」；候选是选项不是暗示。
- 不跳过冲突检查去「先定了再说」。
- 不在没有已锁构思案时动全稿。
- 不写镜号/机位/分镜表——那是下游的活。
- 不碰小说正文；要写小说走 story-long-write / story-short-write。
