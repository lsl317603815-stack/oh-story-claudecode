# 对白自然化法则（去 AI 味）

写作层 **L5（单集剧本）** 的 line-level playbook，与 `dialogue-action.md` 配对使用。

> **两篇的分工**：`dialogue-action.md` 管「**说什么 / 这句的功能**」——信息前置、潜台词动作化、动词链、一句一功能；它保证台词**高效、可拍、不迷路**。本篇管「**怎么说才像真人**」——同样一个功能，用什么口吻、什么句法、藏多少、漏多少，落出来才不像 AI 念稿。**两篇不矛盾，是骨与肉**：`dialogue-action` 把骨架立直（观众永远不迷路），本篇给骨架长肉（观众身体前倾）。

> **一句话立场（也是对 `dialogue-action` 法则一的精校）**：**「信息前置」≠「直白陈述」。** 信息前置是对**观众**说的——开场钩子、爽点、反转必须直给，让观众秒懂。但角色**对角色**说话时，把「信息前置」推到极端（自报身份、自报动机、当面给对方下评语、把主题念出口）恰恰**制造** AI 味。真相是：**最高效的台词常常是最斜的台词**——反派笑着说「你来了挺好，我正想歇歇」，观众脑内自动补上「他怕你抢位置」，这次「自己补完」比你写出来代入感强十倍，且只用一句话同时交代了关系+情绪+悬念。**斜不是慢，斜是用更少的字办更多的事**，这恰恰是短剧最想要的密度。

## 一、AI 味七宗罪（逐条自查 + 真实 before→after）

每宗罪给 **症状 / 自查判据（可逐条过）/ 改法 / 一条真实重写**。判据命中即中招。

### 罪 1：ON_NOSE_THEME — 把主题/人物弧光贴脸说出来

> 创作者心里的「题眼」直接塞进角色嘴里。最典型、最致命、短剧重灾区。

- **症状**：角色（尤其旁观者/智者型）说出一句能直接抄进「主题阐述」的话，把全剧母题点破。
- **自查判据**：这句话能不能原样抄进剧本梗概的「本剧讲的是……」？能 = 中招。出现「自由 / 被困住的孩子 / 没人认得的影子 / 不肯踢球的人」这类**带哲思味的抽象名词**，几乎必中。
- **改法**：把抽象主题词换成一个**具体感官锚点**（眼神 / 一个动作 / 一件物），主题靠潜台词渗，绝不说破。让旁人只负责「勾」，把母题留给主角的 OS 去承载。

```
✗ 程西安：又是个内心被困住的孩子啊。        ← 评论腔 + 贴脸点母题
✓ 程西安：这眼神……我见过。                ← 具体锚点(眼神)+留白；"我见过"暗扣他知情却不说
```
> 同款病在本剧反复出现，改法一致：
> ✗ 高远：球到脚下这一下，多自由啊！ → ✓ 你踢一下就停不下来了，信不信！（只说"球上瘾"，不说"自由"，母题留给凌川 OS）
> ✗ 程西安：什么都不缺——就缺一个，不肯踢球的人。 → ✓ 这队不缺人……缺的那个，自己藏着呢。（从"说主题"转为"点人"）

### 罪 2：SELF_NARRATE_INTENT — 角色把自己的动机/计划念给观众听

> 独白或自语时，把「我接下来要干嘛 / 我真正想要的是什么」一字不漏报出来。

- **症状**：人物对着空气（或背影、或自己）完整总结自己的动机、计划、心境。
- **自查判据**：这是独处/OS 拍，台词却像在做「内心旁白解说」？真人不会对自己这么完整地总结。前面动作已经演了同一件事，台词还抢着说一遍 = 中招。
- **改法**：删掉「计划陈述」，换成一个**对人的挑衅 / 一句自我指令 / 一句轻佻的自得**，决心仍在但不说破，留给眼神、眉头、嘴角去演。

```
✗ 江晚：那脚停球……我非把他挖进队不可。     ← 向观众自白计划
✓ 江晚：就这一脚……你还想躲？               ← 翻成对背影的挑衅，决心在"你还想躲"，且"躲"扣凌川母题
```
> 更多同款：
> ✗ 凌川(OS)：再忍一阵……没人会发现。 → ✓ （OS）别回头……装不知道。（总结性自陈→当下自我指令）
> ✗ 江晚(独语)：……还真往我队里送上门了。 → ✓ 我还没出手呢。（删算计，只留"占主动"的余味，靠挑眉演）

### 罪 3：STATE_EVAL — 鉴定书式属性陈述（当面给对方下评语）

> 直接评价对方的属性 + 下结论，像在念鉴定书 / 招募说明书。

- **症状**：「你是有 X 天赋的」「这么好的苗子」「你这技术很厉害」——对人下属性判断、盖戳。
- **自查判据**：这句是「**对人的属性下结论**」而非「**对刚发生的事的即时反应**」？出现「你是……的 / 这么好的 / 很厉害 / 正合适」= 中招。真人是被一个**动作**勾住，不是在给人贴标签。
- **改法**：把「属性结论」换成「**对具体动作的当场指认**」——先抛具体（哪个角度/哪种球路别人停不住），判断藏在惊讶背后，不盖戳。用观察证据替代属性结论（show，不 tell）。

```
✗ 江晚：反应快？那是预判！你是有足球天赋的，我不会看错～   ← 鉴定书+念功能+广告体
✓ 江晚：反应快？那叫预判。这眼神，骗不了我。              ← 指认动作+读"眼神"这个外部线索
```
> 同款：
> ✗ 江晚：哎，刚才那一脚停球，太漂亮了！ → ✓ 那球都贴地拐了，他一脚就给摁死了？（先抛刁钻球路+具体处理，再用反问"?"让惊叹从眼里漏出，不盖戳"太漂亮"）
> ✗ 江晚：同学，你这身板，踢前锋正合适。 → ✓ 哎——同学，来都来了，跟我们踢一场，我们正缺前锋。（"评价他身板"→"陈述己方需求"，用动作逼近替代评价）

### 罪 4：EXPO_DUMP — 信息倾倒（借角色之口给观众交代背景）

> 把一串信息工整报齐，唯一的听众其实是观众。「招募启事 / As-you-know」式。

- **症状**：对一个连名字都不知道的陌生背影，喊出完整队名 + 具体位置 + 给的条件，信息太齐像启事。
- **自查判据**：这句把「身份 + 缺口 + 给的位置」三件事一口气列清了？真人挖人会**先勾再亮底牌**，不会一次报完条款 = 中招。
- **改法**：信息靠**场景上下文承载**（观众刚看完戏、瞬间能懂），台词砍到两三个短促 tag，保留钩子但不像广告。或把信息放进冲突里挤出来。

```
✗ 江晚：这么好的苗子不踢球可惜啊，南城足球队前锋位置给你留着！  ← 队名+位置报全=启事
✓ 江晚：喂——这脚法，说不踢就不踢？前锋，给你留着。            ← "南城队"由场景承载，留位钩缩成短 tag
```
> 同款：
> ✗ 江晚：我是南城队经理，就缺个前锋。你来，主力。 → ✓ 你这脚下……我们正缺个前锋。来，主力给你。（删自报身份"我是经理"，先夸技术勾再亮底牌）

### 罪 5：AWKWARD_REGISTER — 用词层级不对（书面腔 / 翻译腔 / 语气符号代演技）

> 句子太完整太书面、文艺评论腔、对偶格言体，或用「～」「呀」替演员演情绪。

- **症状**：① 书面判断句式（「是有……的」「把你的身份公开」）；② 文艺评论腔（「内心被困住」）；③ 对偶格言体（「藏得了脸，藏不住停球」）；④ 语气符号替演技（追人拦人却用「～」软成客服）。
- **自查判据**：念出声拗口吗？这句像「写出来的金句」还是「脑子里闪过的念头」？老教练/少年/门将的嘴里会蹦这个词吗？对仗工整 / 主谓宾齐全 / 有英式从句感 = 中招。
- **改法**：① 拆对仗成长短不齐的口语短拳；② 抽象书面词换大白话；③ 砍缓冲与定语；④ 删语气符号，情绪交给动作。

```
✗ 沈渊：你藏得了脸，藏不住那一脚停球。       ← 写出来的对偶格言 + OS 替观众旁白"我认出他了"
✓ 沈渊：脸，我认不出。这一脚停球，骗不了我。   ← 拆成两记短促直拳，无对仗，当面逼问
```
> 同款：
> ✗ 程西安：藏脸，藏得住；藏脚，藏不住。 → ✓ （呷一口热茶，目光落在那双脚上，低声）脸啊，能藏。脚下那点东西……藏不住喽。（口语反对仗 + 气声自语舞台业务，金句去棱角）
> ✗ 江晚：同学！谢谢你刚才替我挡那一下～ → 删「～」（追人拦人的劲头不该被软成可爱客服；语气符号在替演员演情绪）

### 罪 6：VOICE_SAMENESS — 所有人一个腔（台词可任意互换）

> 遮住人名认不出谁；标语式狠话换任何强势角色都成立，缺角色专属的具体感。

- **症状**：「我盯上的人，还没跑掉过」「这身板往门里一杵比门框还宽」——为立人设而写的标语 / 准备好的网络梗，节奏太顺、包袱太齐。
- **自查判据**：把这句换给另一个强势角色读，毫无违和？或读起来像「脱口秀 / 漫画反派腔」而非「当下反应」？= 中招。
- **改法**：回到这个角色**当下处境**的真实反应——摔一脸泥爬起来是骂咧咧的碎句，不是段子；给角色专属的具体感（见第四节声音卡）。

```
✗ 江晚：嘴硬。我盯上的人，还没跑掉过。   ← 标语式狠话，换任何强势角色都成立（VOICE_SAMENESS）
✓ 江晚：嘴硬。——你越躲，我越来劲。       ← 收回当下处境：被噎住还要占上风的招募官，"越躲越来劲"扣她惜才 + 凌川"躲"母题，只有此刻的江晚说得出
```
> ⚠️ 区分「标语」与「招牌」：牛壮的自黑吹牛（「这身板一杵，比门框还宽」）是**他专属招牌**、不算 sameness；VOICE_SAMENESS 指的是**换个角色照样成立**的通用狠话/段子。判据永远是第四节「对调测试」，不是「听起来像不像梗」。
> 更多修法见第三节「各怀目的」与第四节「声音卡」——让这句**只有这个人**在**这个处境**才说得出。

### 罪 7：NO_SUBTEXT — 嘴心一致，毫无潜台词（直球）

> 有问必答、零回避、情绪与台词 100% 对齐；或把悬念/埋线直接用独白讲穿。

- **症状**：被问痛处老实直答；高兴说高兴的话、在乎说在乎的话；把「似曾相识→记忆」这种该藏的闪念用 OS 点破。
- **自查判据**：这句心里话被说白了吗？这个回答是「正面老实接话」还是「有回避/反问/岔开」？画面已经演了的事，台词又口播一遍？= 中招。
- **改法**：把直接回答换成**回避 / 反问 / 岔开的具体话**；把闪念翻成**自嘲式否认**（只演不说）；在脆弱/在乎的高点引入**反话**，真心交给表情和动作漏。

```
✗ 江晚：这道弧线，和我记忆里那个人，怎么会一样。   ← 内心独白直接点破海报埋线
✓ 江晚：（怔了半秒，又笑自己）……我是不是看球看魔怔了。  ← 把眼熟当错觉笑掉，似曾相识只演不说，观众独享真相
```

### （附）ON_NOSE_EMOTION — 直接口播情绪（罪 1 的情绪版）

- **症状/判据**：台词把情绪直接命名（「怎么不理人」「不敢看」），且动作已演了同一件事，台词抢着解释。
- **改法**：情绪交给已有的动作（泄气、跺脚、移开视线），台词留半句嘟囔或干脆无声。

```
✗ 凌川：那片场子，我连多看一眼都不敢。   ← 动作已演"脚步顿半拍+移视线"，台词又口播"不敢看"
✓ 凌川：那地方……没我的事。             ← 改成"撇清/划界"，恐惧藏在停顿与动作底下，嘴上不露怯
```

### （附·2026-06-09 升级）七宗罪 = 带豁免位的「软 linter」+ 三宗新变体

> 124 部爆款回采的最大修正：**七宗罪在顶级爆款里 100% 复现——连最顶的也在犯。** 区别从来不在「犯没犯」，而在「**谁说、说几次、靠什么救回**」。所以七宗罪不是「命中即废」的硬 linter，是**带豁免位的软 linter**：定罪前先问一句「谁在说」。

**软 linter 豁免位（校准罪 2 / 3 / 4）**
- **罪 3 STATE_EVAL · 反派豁免**：反派下脏评语（「废物 / 不配」）服务「让观众恨他」时是**爽点弹药**，配额 **≤2 次/剧**；超配、或**主角**下评语 = 真 AI 味（《武神归来》李经理骂「废物」=反派功能 card_088；同句给主角即崩）。
- **罪 4 EXPO_DUMP · 载体 + 位置豁免**：信息塞进**合同 / 公告 / 形式感世界规则**=合理（书面腔在书面载体里不违和，card_027）；竖屏 1 分钟的**前几集世界观建置位**是结构性妥协，靠「**拆给多人吵着带出**」降味（card_110）。但**情绪 / 生死 / 对峙位零容忍**；两个知情角色互相补课、一人背简报/罪状/百科 = 中招。
- **罪 2 SELF_NARRATE_INTENT · OS 情感型豁免**：OS 念**情感**（不甘/心疼/恐惧）合法且高频，是双轨真心声道；OS 念**计划**（「下次我要…」「先 A 再 B」）仍中招。每场 OS **≤2 条**。好 OS = 当下情绪碎片 / 思维问句 / 一句反话（「是谁？怎么这么巧？」）；坏 OS = 完整动机 + 计划书（《腹黑女佣》「我进这个家就是为了撕开她的假面」card_100）。

**三宗新变体（补进 linter）**——都是 VOICE_SAMENESS / SELF_NARRATE 的特化，124 部高频实犯：

**变体 8 · ECHO_CONFIRM 镜像确认** — B 复述 A 刚说的信息当「确认」，替观众把信息点逐一坐实。
- 判据：第二个人的台词能不能换成「点头 / 一个推进性追问」而不丢信息？能 = 中招。
- 改法：删复述，B 只给「情绪反应 + 一个推进性动作/追问」。
- 实犯：《生物老师》何铮听见「她发现了」后连环确认「她发现了？/谁？/吴雪？/她发现什么了？」（card_053）——真人先有情绪反应再追问，不会立刻切入逐条信息获取。

**变体 9 · MOUTHPIECE_NPC 功能性工具人** — 配角是主角思维 / 世界观的扩音器，自己没有反应逻辑。
- 判据：遮住名字，这个 NPC 像不像「解说员」？那句话的真正受众是不是观众而非场内人？= 中招。
- 改法：给 NPC 自己的小目标 / 情绪；世界观拆进主角行动；推断留给该推断的人。
- 实犯：刑侦剧小五汇报「他跟沈天并无过节」（card_037）——这是作者替观众总结「那为什么杀她」的疑问，小五只该报事实，推断留给下一句沈行之自己问出来。
- ⚠️ 正用法（别误杀）：让旁观者**替观众读出主角的潜台词**是好技法（《天降多宝》老三旁观「最后一定是二哥舔着脸追妻」card_000）——区别在 NPC 有没有自己的态度/立场，纯背设定才是工具人。

**变体 10 · REGISTER_SPLIT OS 腔与对白腔断裂** — 同一角色嘴上口语、心里文艺，声音内部裂开（对调测试查横向，这条查**纵向同角色内部**）。
- 判据：把该角色 OS 和对白并排读，像不像两个人？对白口语、OS 却冒出定语从句 / 议论文腔？= 中招。
- 改法：OS 与对白用**同一把嗓子**——OS 的 register 锚点 = 这个角色对白的 register 锚点。
- 实犯：《顾总千金有点毒》陈菲菲对白「回，回什么家？我们才谈了三个月啊」（紧张口语带重复中断）vs OS 哀怨文艺书面腔——两套声音明显割裂（card_046）。
- 反例（故意切换=签名，不算病）：《女帝当太医》宋晨平时「老子/尼玛」，危机才硬切「臣」——这是**有意的 register 跳变**，是声音卡而非 bug（见第四节引擎①）。

## 二、让台词像真人的五个核心手法

七宗罪是「别做什么」，这五条是「该做什么」。每条配真实例。

### 1. 潜台词：说出口的永远不是真正想要的

人物有策略、有战术，从不把心里话完整说出口。**文本（说出口的话）和潜台词（真正的欲望）必须错开**——台词越斜，张力越大，观众靠语境自己补回真话，这一补人就进戏了。

- **写法**：先写人物真正想说的那句赤裸真话，再换成一句「绕着它走」的话。`赤裸真话「我离不开你」→ 斜句「你走啊，冻死在外头别回来找我」`——真话一个字没说，全漏在反话里。
- **正样本**：凌川`「我不会。」`——明知他会、偏说不会，口是心非的潜台词全在两字里；`「想躲一辈子？球场又不是你家的坟。」`——用「坟」这个具体意象戳人，而非直说「你在逃避」。

### 2. 答非所问：人会回避、转移、反问，不老实接话

真人对话很少是「问—答—问—答」的乒乓球。被问到痛处，人会岔开、反问、装没听见。**答非所问本身就在传递信息**（他在躲什么、更在意什么）。「问答式对白」是中文剧本论反复点名的最假信号。

- **写法**：把直接回答替换成一个回避、一个反问、或一句岔开的具体话。`✗「我不想谈这个。」→ ✓「……几点了，我得走了。」`——用一句岔开的具体话，把「不想谈」演出来而不说出来。
- **正样本**：凌川`「我不认识你说的人。」`——不正面接「停球」而岔到「人」，冷、短、闪躲。
- **爆款主流是「夺权型」不是「回避型」**（124 部回采校准）：答非所问真正在做的是**夺取叙事主动权**，4 子型——①翻转审问权（《古代当花魁》被掐脖反将`「你这么关心我和别的男人，该不会是喜欢上我了吧？」`card_025）②降维到另一坐标系（《无双》`「你，砸了我的饭。」`card_113）③原话奉还（`「你说了我会信吗」→「我说了你会信吗」`card_097）④跳过问题直接接情感底线（道歉「是我错了」只接「钱」那层`「家里真没钱了！」`card_117）。本剧用①③：凌川被逼认账→不辩解，岔到`「你认错了」`（守身份=换议题）。

### 3. 具体代评价：用一件物、一个动作替代抽象总结

人不说「我很爱你/很愤怒/关系破裂了」，而是说具体的事、指具体的物、做具体的动作。**抽象形容词是台词里的脂肪**，越具体越有血肉。

- **写法**：每出现一个情绪/评价词，就换成一个能拍出来的具体物或动作。`✗「他技术很强。」→ ✓「那球都贴地拐了，他一脚就给摁死了？」`——「强」字不出现，强全在球路里。
- **正样本**：江晚`「那球都贴地拐了，他一脚就给摁死了？」`——「漂亮/厉害」一个没出现，技术之强全在具体球路里。
- **结构级用法**（124 部回采新增）：同一道具**前后呼应两次**可独立承载整条情感线——《腹黑女佣》「糖」贯穿全剧（八岁后不吃糖 = 我记得你怎么骗我的，card_100）、《武神归来》狗尾巴草戒指求婚（card_088）。道具不止单场景，可做整条线的锚。**进攻版**：骂/威胁也要具体到能拍才有打脸快感——`「老大穿星期一、老二穿星期二」`>「你很穷」（card_000）。

### 4. 沉默、打断与半句噎住：节奏即情绪

对白有音乐属性（节拍、休止、重音）。人会打断、抢话、自我打断、被情绪卡住说半句。**最重的话常是没说完的话和那一拍沉默。** 一段全是完整句、你一句我一句对仗工整的对白，必假。

- **写法**：情绪顶点删掉后半句让它断在最痛处；让强势方打断弱势方；用动作或「……」承接说不出口的话。
- **正样本**：沈渊`「……天马。」`（两字砸进暗处，全是潜台词，省略号外化危险节奏）；高远`「刚……刚才那一下……」`（震撼到失语，结巴+未尽句模拟真人当场说不出话）。

### 5. 各怀目的：一场戏里两人要的根本不是一件事

好对白不是两人合作把信息说清楚，而是**两股不同的「想要」在同一段话里互相碾压**。写双人戏先各写一行：A 这场要什么、B 这场要什么——若两个目标一致，戏就死了，必须错位甚至对撞。

- **写法**：先问 Mamet 三问——谁、想从谁那里、要什么；得不到会怎样；为什么是现在。把「交代信息」的句子删掉，换成「用这句去拿到那个东西」。
- **正样本**：2-4 沈渊要逼凌川认账（`「认错？手抖什么。」`——抓现行式反问，把威胁压进一个生理细节），凌川要咬死不认（`「……你认错了。」`——三字否认+停顿）。表面在争「认不认得」，底下是「逼归队 vs 守身份」的对撞，谁都没说破。

## 三、中文口语工具箱（去书面腔的手术刀）

把书面句改成口语句的具体技法。**念出声改，拗口就是假。**

### 语气词：调态度、软硬度、亲疏

| 语气词 | 作用 | 别用在 | before → after |
|---|---|---|---|
| **吧** | 软化命令/提议、把断言降成商量或揣测 | 反派亮底牌（泄气） | 「你现在就走。」→「你先走吧。」／反例：亮底牌写「跪下，道歉」不写「跪下道歉吧」 |
| **嘛** | 「这不是明摆着的吗」/撒娇/讲道理的理所当然 | 严肃对峙（显轻佻） | 「这件事本来就不怪我。」→「这又不怪我嘛。」 |
| **呗** | 满不在乎的「那就这样咯」、赌气随意 | 体面/正式语境 | 「你不信，那我也没办法。」→「你不信拉倒呗。」 |
| **啊/呀** | 软化强硬、口语垫音、表惊讶/亲近 | 满篇都加（显腻） | 「你来了。」→「你来啦。」 |
| **呢** | 追问余味/状态持续/反问的不服气 | 陈述句乱加（怪） | 「凭什么是我让步」→「凭什么是我让步呢」（多一层委屈不甘） |

> ⚠️ **语气词不是越多越自然**——只在需要软化/惊讶/不服处点。该斩钉截铁的地方加「吧」会泄气（亮底牌别写「你跪下道歉吧」）。

### 省略主语/成分：中文口语极少说全

书面腔的标志就是主谓宾齐全。能省则省，全凭语境补，省略后更紧、更像脱口而出。
```
「我得走了，我明天还要早起。」→「走了，明天得早起。」
「你吃饭了吗？」→「吃了吗？」
```

### 半句噎住 / 「……」断句：情绪卡住或被打断

完整句太多 = 假，关键处必须留断口。本剧实证：
```
✗ 三年了，我只想当个没人认得的影子。   ← 书面总结句，独白不会这么完整
✓ 没人记得，最好。                     ← 删时间状语+动机直报，逗号切一刀制造半句噎住
```
> 手法：把「主题标语」降格为「态度碎句」——只留一缕情绪，用逗号/省略号模拟真人内心的不连贯。`「最好」`二字落地更短促，像走神时甩出来的一句心里话。

### register 调校：同一句意按身份/年龄/处境换皮

这是让「所有人一个腔」破功的**总开关**。同样「你别管了」：
```
长辈对晚辈——「这儿没你的事，一边去。」
下属对上司——「这边交给我就行，您放心。」
哥们之间  ——「得得得，我来，你歇着。」
```
> 本剧 register 锚点：粗人用短句脏字（牛壮`「我操，牛逼！」`零修饰纯生理反应=全剧最像活人的一句）、少年人莽撞抢话（高远`「学长！踢球吗？我们就差一个人凑齐了！」`急吼吼制造亏欠感）、冷硬主角短句否认（凌川`「我不踢球。」`三字回避而非解释）。

### 正话反说 / 嘴硬：把在乎包进反话里

强烈情绪常用反话包装：在乎说「随便你」，挽留说「你走吧没人拦」。反差让真心更动人。
```
「你别走，我很担心你。」→「走啊，冻死在外面别回来找我。」（嘴硬，心软全在语气）
```
> 本剧正样本：江晚`「去去去，你才看上他了...」`——用否认掩饰自己确实盯上了人，傲娇潜台词，专属江晚的伶牙俐齿，换别人说不成立。

### 糖衣台词（攻击向）：表面求情/夸赞/关心，杀意全在语境

区别于上面「正话反说」（亲密向：在乎说随便）——这条是**对峙/攻击向**：字面挑不出毛病，杀意全在语境。
- **7 种糖纸**：求情 / 祝福 / 比喻（兔子·猎物）/ 反问 / 关心 / 自陈病情 / 留位子（名片）。
- 实犯转用法：《焚心成焰》宫小倩当面「求情」`「孩子是无辜的啊」`实为落井下石（card_022）；《生物老师》`「让她永远陪着你」`=用模糊祝福语下杀人指令（card_053）。
- **落地沈渊**：压迫别写直骂，写「夸」——`「你这脚法，埋在野球场可惜了」`（糖纸=惜才，刀=逼归队），比「不然公开你身份」高级、且凌川当场难反驳。

### 方言/地理锚：配角点 1-2 个，主角保标准腔

文档原本完全缺。规律高度一致：**配角用方言词做地理/阶层锚，主角保标准腔（权威感）**。偶像剧尤其——主角群保普通话，方言留边缘配角（食堂阿姨/客场地方教练）。
- 速查：喽/呗（江湖随意）、嘛（西南/北方软化）、伐/懂伐（沪语权力感）、俺/俺们（东北/西北质朴）、咧/嘞（西南）、侬（吴语）。
- 实犯：《风流外卖员》`「在魔都，你这种小赤佬想挣钱，就要像狗一样趴着，懂伐？」`（card_108）。

### 骂中带宠三结构：用最不严肃的小事当攻击载体

骂词是亲密特权的证明。**想写宠，先写骂，再抽干杀伤力，真心交给动作漏。**
- ①**诅咒三连**（缺失物升级：筷子→调料→纸；真撕破脸不会咒这些·《狂飙大嫂》）②**昵称骂**（傻儿子/呆鹅=接受关系又拒绝示弱·《穿越助妈》`「傻儿子别装了，赶紧跑！」`card_011）③**骂第三人来宠你**。

### 骂战 / 对骂：一种可拍的「逐轮升级」冲突结构

（124 部回采补——之前只写了单人输出，漏了你来我往。）真人冲突常是 **A 骂 → B 回更狠 → A 加码** 的逐轮升级：每轮换一个更具体的抓手、句子越来越短、**上一句的某个词被下一句抓住反打**。直接可用于**凌川 ↔ 沈渊 / 客场对手**的正面冲突戏——别写两段独立狠话，写成接力，火力一轮比一轮密。

### 诚实毛刺三件：替形容词（字面层）

「很贵/很怕/很尴尬」换成可拍的具体：**数字**（`「一千年才买得起」`=口语随口算，非书面「遥不可及」）/ **身体反应**（肚子咕噜、咽口水、流鼻血）/ **拟声词**（吱吱唔唔、沙沙沙）——比形容词诚实。

### 称呼杠杆：不喊名才是日常，喊名是情绪决堤

给关键两人定**默认称呼**（同学/他/那小子），只在**情绪顶点/关系质变**破一次默认，破的那一下=全场最重的台词。《腹黑女佣》全剧女主几乎不喊男主名，到顶点连叫四遍`「顾旬」`（card_100）。**本剧 canon「江晚不喊凌川名」不只是防穿帮，是情绪杠杆**——到 E003 关系质变第一次喊「凌川」本身=台词级事件，在那之前所有招募戏都在蓄能。

### 语言崩塌梯度：治「他惊恐地/愤怒到说不出话」

轻度犹豫`「这……/我……」`→ 中度慌乱重复首音节`「我我我」`→ 语塞愤怒单字句`「你！」`→ 死亡/被打断 半句断在动作发生那一刻。⚠️**分工**：配角用「我我我」崩，主角凌川的崩是`「……你认错了」`的**停顿**（别破他的冷）。

### 权力越高句子越短

长句=弱势/解释；狠话靠零修饰而非加狠词。《恋恋红尘》媚姐`「走！」「嗯。」「带进来！」`（card_030）。**反 AI 判据**：写狠话时若在加形容词/排比/「你给我听好了」前摇 → 删光留最短核。凌川 >4 字硬顶即报 bug。

### 口语肌理 linter（语音/字面层 —— 治「太干净太书面」，接七宗罪 linter 之后逐句过）

> 七宗罪 linter 管「别贴脸、别倾倒」（语义层），本块管「同一个意思，怎么用活人的舌头说出来」（语音/字面层）。用户「太干净太书面」的病，主要靠 T1–T10 治。


## 四、声音差异化：给每个角色一张「声音卡」

**自查总开关——对调测试**：遮住人名读对白，认不出谁是谁，或把两个角色台词对调后读着照样通顺 → 全员共用作者一种语感，VOICE_SAMENESS，必须重写。**对调通不过才算过关。**

写台词前，先给每个出场角色填一张声音卡（方法论级，任何题材通用）：

| 维度 | 怎么定 | 本剧示例（供格式参考，非绑定） |
|---|---|---|
| **句长** | 由性格/处境定：冷硬短、莽撞短促、心机绵长 | 凌川=极短（2-4 字）；沈渊=短促见刀；程西安=气声拖尾 |
| **语气词** | 选 1-2 个高频，别人不用 | 程西安=「啊/喽/呢」端着茶自语；江晚=市井网感动词 |
| **词汇层级（register）** | 身份/年龄/教育/出身定 | 牛壮=生活化脏字；江晚=「怼脸/摁死/贴地拐」；凌川=不带情绪词 |
| **标志句式** | 一个反复出现、一认就是他的句型 | 凌川=否认母题变体（「我不会」「你认错了」「没我的事」）；沈渊=抓现行反问（「手抖什么」「我看到了」） |
| **绝不说的话** | 划出这个角色嘴里不可能出现的词 | 凌川绝不说「自由/影子/我害怕」（哲思词+示弱词）；沈渊绝不用语气符号软化；少年门将不说「跑得了和尚跑不了庙」这类老气俗语 |

> **声音卡是 VOICE_SAMENESS 的疫苗**：填卡时若两个角色的五行高度重合，说明人物设定本身没拉开，回 L2 人物层补差异，别在台词层硬掰。
>
> ⚠️ **声音卡与剧情 canon 联动**：本剧硬约束「江晚此阶段不知道凌川名字」→ 江晚所有招募台词**绝不喊名**（用「同学/他」），这既是 canon 也是她的声音卡一条。改台词时**先过 canon 再过自然度**——一句再自然，违了 canon（喊名/越界推断身份/腔调跑偏）也得推翻。

### （2026-06-09 124 部回采）声音卡补四个被验证的引擎 + 升「绝不说的话」为前置工序

**引擎①·自称 = 一键声音标签**（成本最低的声音指纹）：老子/老娘=「我不亏欠你」；爷=江湖市井；本宫/朕=权力顶端；第三人称报姓名（`「我徐媚……」`）=越自报越是警告；慌乱时换自称（我→臣，宋晨一句改三次 card_027）=情绪破碎。

**引擎②·双声道（OS 层 / 对白层分裂）= 单角色内部签名**，两条铁律：①OS 不重复对白（对外「没脸见人」，OS 立刻给新信息 card_023）；②反转/揭穿用对白钉、不用 OS 解释。⚠️ 但 OS 与对白必须**同一把嗓子**（见第一节罪变体 10 REGISTER_SPLIT）。

**引擎③·声音演变弧 = 觉醒/转折落在台词层**：句子变短 + 动词变硬 + 解释消失（《屌丝巨富》穆城 集1`「你怎么能…你这个拜金女」`弱书面 → 集5`「是我开除的你 / 莫欺少年穷」`短促不解释 card_051）。落地：让**宿敌见证**成长比朋友更有力——沈渊后段`「你变了，以前你不这样踢球」`。

**引擎④·男女声腔差有稳定结构**：男主向核心=不解释、只给结论；女主向=不示弱、用反问出拳。交集「不解释 + 不直白 + 不示弱」=强势主角性别公约数。

**「绝不会说的话」升为前置工序**（124 张卡无一例外明列）：每个角色第一次开口前必填，三大禁区聚类——①不解释 ②不直白表态 ③不示弱认错。

**register 从「静态换皮」升「动态跳变 = 签名」**：切换动作本身比任一档位更标识人物（《我在古代拿offer》王婆`「好嘞跟我走吧！」`→ 签完合同`「小心我剥了你的皮！」`翻脸速度=最大标志 card_077）。

**句长「长短诊断法」量化**：强势角色本色态 **≤8 字**；写出长句先问「**是在表演吗**」（《死对头竟是保镖》阮星元全剧唯一长句是演给记者看 card_045）；凌川 >4 字硬顶即报 bug。

## 五、效率↔自然的调和：什么时候直给 vs 什么时候走潜台词

短剧要「信息前置、台词高效、一句一功能」，与「潜台词、不直说」看似冲突，但**二者管的是不同对象**：

> **对观众要直给（结构清晰），对角色之间要走潜台词（关系有张力）。**

用直给的台词搭**骨架**（让观众永远不迷路），用斜着说的台词长**血肉**（让观众身体前倾）。这是分工，不是对立。

### 判定表（写每句台词前过一遍）

| 这句台词服务谁/干什么 | 直给 ✅ 还是潜台词 ↘ | 为什么 | 例 |
|---|---|---|---|
| **开场三秒钩子**（谁/什么处境/悬念在哪） | **直给** | 服务观众认知，秒懂优先 | 「三年了，你终于敢回这个家。」 |
| **打脸/亮底牌爽点**（要能被截图传播） | **直给** | 爽点要砸得响、干脆狠绝 | 「你刚才说我配不上？现在，跪下道歉。」 |
| **生死/动作指令**（快跑/别开门/没子弹了） | **直给** | 零延迟，潜台词会要命 | 「枪里没子弹了。」 |
| **身份/反转揭晓句**（反转落地那一锤） | **直给** | 要清楚响亮，让观众接得住 | — |
| **人物关系**（爱/恨/亏欠/试探） | **潜台词 ↘** | 直接命名即廉价，靠物/动作/反话漏 | 「你来了挺好，我正想歇歇。」 |
| **内心戏**（动机/恐惧/不甘） | **潜台词 ↘** | 说出口即失重，留给眼神/半句/答非所问 | 凌川(OS)「别回头……装不知道。」 |
| **对峙与试探**（两个高手过招） | **潜台词 ↘** | 谁先把底牌说白谁就输了张力 | 沈渊「那脚停球，我看到了。」 |
| **暧昧/未明情感** | **潜台词 ↘** | 观众要的是「就差一层窗户纸」的痒 | 江晚「我是不是看球看魔怔了。」 |

### 核心洞察：最高效的台词往往是最斜的台词

**潜台词让观众替角色把话补完**——反派笑着说「我正想歇歇」，观众脑内自动补上「他怕你抢位置」，这次自己补完比直接写出来代入感强十倍，且一句话同时交代了关系+情绪+悬念。**所以「斜」不是「慢」，斜着说常常是用更少的字办更多的事**，这恰恰是短剧最想要的密度。

### 短剧实操落法

- **配比经验值**：一场戏 = 开场钩子句 + 收尾爆点句**直给**（占两三句），中间的关系/对峙/试探全部**走潜台词**。骨架直、肉斜。
- **「一句一功能」照旧守**：但功能可以是「推进剧情」也可以是「撕开关系」——后者用斜句完成，不浪费。
- **「夸张可拍」与潜台词不冲突**：把潜台词锚在一个能拍的夸张动作上（把钥匙拍桌上、把外卖箱摔地上、笑着把递来的水推回去）。**动作负责夸张可拍（`dialogue-action` 法则二/三），台词负责斜**——镜头反而更好出。
- **金句配额**：漂亮话一场戏一两句封顶（留给关键人物的关键时刻），多了就稀释成「全员段子手」，反显假。**题材腔豁免**：男频战神/霸总/女帝的书面气场自称（「赔！」「骁龙吟。」）按「招牌」豁免；唯一红线是**用书面成语给别人行为下评语**（狐假虎威/丧尽天良）=伪装成台词的 STATE_EVAL，必删。

### 功能位法则（124 部回采新增——台词在竖屏结构里站的四个岗）

- **开局：困境前置、身份后补**——第一句永远是正在发生的冲突，不是自我介绍（《仙界赘婿》开口`「住院费手术费红包一共六十万，你有吗？」`card_070）。⚠️ 直给的是**处境/威胁**，不是身份/前史（「三年了你终于敢回这个家」把前史也直给了，合格不最优）。
- **反转走三拍 + 爽感 ∝ 反派蠢话体量**——预期→打破→极简收割。打脸句越短越狠，弹药全在前面反派的废话铺垫里（《天降多宝》反派「碾死你跟碾死蚂蚁一样」→ 男主`「哦？霍氏，这么巧，我也在霍氏工作。」`card_000）。
- **集尾钩 = 悬停在「已知未说」那一帧**——绝不用总结句结尾，停在「将揭未揭」（《封总》看到检查单放回包里没说，关键信息停在镜头里 card_005）。
- **分层打脸 + 公开见证**——每层比上层更狠，**旁观者越多越爽**，打脸不在私下发生（《警告别惹总裁》6 层叠加 card_001；《八零后妈》「所有打脸都发生在旁观者存在的场景里」card_110）。

### OS / 对白分轨（OS 的四个合法功能）

对白是**演给场内对手的表演层**，OS 是**只给观众的真相层**，两轨信息**不重叠**。OS 四功能：①真相轨（嘴上一套心里一套）②账本（给观众看账本）③陪观众一起懵 ④拉平信息差。⚠️ OS 一旦念「我接下来要 A 再 B」就是 SELF_NARRATE_INTENT（《腹黑女佣》「我进这个家就是为了撕开假面」card_100）——OS 只许情感型，不许计划书。
