# 节奏曲线设计

## 核心理念：张弛有度，让观众上瘾

微短剧的节奏不是"一直爽"，而是"紧→松→更紧→松→最紧"的波形。就像过山车，持续加速反而麻木，有起有落才刺激。

**节奏公式：** 紧张蓄力 → 爽点释放 → 短暂喘息 → 新一轮蓄力

---

## 单集微结构（1-3分钟）

> **情绪弹簧·二元定律**：观众情绪是根弹簧——压（制造误会/主角受压/反派嚣张/危机降临，蓄负面情绪拉满期待）或放（反转/打脸/真相/化解，瞬间释放）。**每一集要么压、要么放，不存在中间态**；写前先定本集是"压"集还是"放"集。给每集情绪峰值打 1-10 强度，连成一条"情绪 K 线"——若连续几集强度持平/单调，节奏就是平的，必须调。连续压不超过 3 集（防情绪疲劳）；全剧最强的"放"压在哪由商业模式定——付费卡点剧压最后、免费平台前置到第一幕收官（见下"全剧节奏波形·先选模型"）。

每一集都是一个完整的"微型三幕剧"：

### 前30秒：钩子段

**任务：** 抓住观众，不让划走

```
结构：
├── 承接上集悬念（如果不是第1集）
├── 抛出本集核心冲突或疑问
└── 建立本集情绪基调
```

**技巧：**
- 第1集：直接用开场模板（参考 opening-rules.md）
- 非第1集：先花5秒回应上集悬念，再立刻制造新张力
- 禁止平淡开场，每集开头都当第1集来写

### 中间1-1.5分钟：冲突升级段

**任务：** 推进剧情，层层递进

```
结构：
├── 场次一：冲突展开（信息量最大的场次）
├── 场次二：压力升级（反派行动 / 误会加深 / 困境加剧）
├── 场次三（可选）：转折或新信息介入
└── 情绪持续上升，不能在中段出现平台期
```

**节奏要求：**
- 每个场次之间要有递进关系，不能平行并列
- 中段不能出现"信息真空"（无新信息的过渡场景）
- 对话节奏要快，删掉一切不推进剧情的台词

### 最后30秒：爽点/钩子段

**任务：** 释放爽点 + 制造下集期待

```
结构（二选一）：
├── 方案A：爽点释放 → 新悬念（适用于常规集）
│   ├── 本集核心冲突的阶段性解决
│   ├── 给观众一个满足感
│   └── 但同时抛出新问题或暗示新危机
│
└── 方案B：极致悬念 → 硬切（适用于卡点集💰）
    ├── 把情绪推到最高点
    ├── 在最关键的一刻切断
    └── 观众必须看下一集才能知道结果
```

## 全剧节奏波形

### 先选模型：观众有没有被付费筛选过（2026-08-14 定档）

全剧强度分布不是通用曲线，先按商业模式选模型：

| | 模型 A · 四阶段递增 | 模型 B · 前置爆点 |
|---|---|---|
| 适用 | 付费卡点剧：小程序/App 前~10集免费+付费解锁 | 红果式免费剧：广告/流量分账，靠完播与留存变现 |
| 机理 | 付费墙筛过的观众有沉没成本、大都走到终点，蓄力越深结算越值 | 完播率逐集递减，**爽点重要度＝强度×还在看的人数**——同一爆点放 E3 与 E33，触达人数差一个量级 |
| 全剧最强爽 | 决战段（最后） | 打脸最强处前置到第一幕收官；尾段峰值改情感向 |

判据一句话：**观众是否先付了钱**。付费筛选过→递增（模型 A）；免费流量每集都在流失→前置（模型 B）。压放弹簧、一事一集、见证者升级、可证伪、集尾钩等单点手段两模型通用，变的只是全剧强度分布曲线。

### 模型 A：四阶段递增波形（付费卡点剧默认）

将全剧分为四个阶段，每个阶段有不同的节奏特征：

```
情绪强度
 ▲
 │           ★                              ★★★
 │          ╱╲          ★★               ╱    ╲
 │    ★   ╱  ╲        ╱  ╲    ★★      ╱      ╲
 │   ╱╲  ╱    ╲      ╱    ╲  ╱  ╲    ╱        ╲
 │  ╱  ╲╱      ╲    ╱      ╲╱    ╲  ╱          ╲
 │ ╱            ╲  ╱              ╲╱            ╲
 │╱              ╲╱                              ╲
 ├──────────┬──────────┬──────────┬──────────────→ 集数
   起势段      攀升段      风暴段       决战段

★ = 高潮点    ╱╲ = 紧张-释放循环
```

### 第一阶段：起势段（前15%集数）

**对应集数（60集为例）：** 第1-9集

**节奏特征：**
- 节奏偏快，密集建立信息
- 高潮强度：★★☆☆☆（小型爽点）
- 每2-3集一个小高潮
- 免费内容区间，必须积累钩子

**核心任务：**
```
├── 建立核心角色和关系（不超过5个主要角色）
├── 展示主角困境（引发共鸣/同情）
├── 制造至少3个未解悬念
├── 给观众"爽"的预告（小规模打脸/撒糖/能力展示）
├── 为首个付费卡点蓄力
└── 最后1-2集免费内容放最强钩子
```

**禁忌：**
- 不要在起势段就把最大的秘密揭露
- 不要出场太多角色导致信息过载
- 不要节奏太慢，"第5集还在铺垫"就晚了

### 第二阶段：攀升段（15%-45%集数）

**对应集数（60集为例）：** 第10-27集

**节奏特征：**
- 节奏稳定上升，高潮间隔缩短
- 高潮强度：★★★☆☆（中型爽点）
- 每5-7集一个中高潮
- 付费卡点密度最高的区间

**核心任务：**
```
├── 主线冲突全面展开
├── 感情线开始推进（暧昧/试探/初步确认）
├── 小反派登场并被击败（给观众阶段性满足）
├── 中反派开始露出獠牙
├── 主角获得初步成长/实力提升
├── 不断制造"以为解决了其实没有"的波动
└── 为风暴段的大爆发蓄力
```

**节奏技巧：**
- "两步前进一步后退"：主角赢两次，然后遇到更大的挫折
- 感情线和主线交替推进，不要同时高潮
- 每次小高潮后给1-2集喘息，但喘息集也必须有新信息

### 第三阶段：风暴段（45%-80%集数）

**对应集数（60集为例）：** 第28-48集

**节奏特征：**
- 节奏最快，高潮密集
- 高潮强度：★★★★☆（大型爽点）
- 每3-5集一个大高潮
- 全剧最精彩、信息量最大的区间

**核心任务：**
```
├── 核心秘密开始揭露（但不是一次性全部揭露）
├── 中反派被击败，大反派正面登场
├── 感情线迎来最大考验（误会/分离/背叛疑云）
├── 主角跌入低谷（全剧最低点）
├── 绝地反弹开始
├── 身份揭露 / 真相大白的关键几集
└── 为决战段铺设最后的伏笔
```

**节奏技巧：**
- 这个阶段是"情绪过山车最陡的一段"
- 主角的低谷不能太长（2-3集），否则观众受不了
- 每次大高潮之间可以穿插感情线甜蜜片段作为调剂
- 反转密度最高，但每个反转都要有前面的铺垫支撑

### 第四阶段：决战段（最后20%集数）

**对应集数（60集为例）：** 第49-60集

**节奏特征：**
- 节奏先紧后收，一路冲向最高点然后迅速收束
- 高潮强度：★★★★★（全剧最强爽点）
- 终极对决是全剧最高潮
- 结局后需要1-2集收束情感

**核心任务：**
```
├── 终极对决前的最后准备（联盟/策略/心理建设）
├── 终极对决（大反派 vs 主角，全剧最高潮）
├── 隐藏反派揭露（如果有，在终极对决中或之后）
├── 所有悬念回收（不能留下未回答的核心问题）
├── 感情线大结局（告白/婚礼/重逢）
├── 配角支线收束
└── 最后1集：情感余韵，给观众满足感
```

**节奏技巧：**
- 终极对决不要只占1集，要给足2-3集的篇幅
- 结局不要拖，高潮之后2-3集内必须全部收束
- 最后一集的基调取决于结局类型：大团圆要温馨，开放式要留悬念余味
- 隐藏反派的揭露时机：在观众觉得"终于结束了"的时候再来一击

### 模型 B：前置爆点波形（免费平台·2026-08-14 用户批注定档）

> 实证锚：《天降女儿》L3 项目大纲用户批注——「爽点节奏完全反了：短剧前 3 集最爽，看到结尾的人没那么多；前 10 集第一幕最重要」。项目级排布正本见该项目 `项目档案/项目大纲.md`「爽点节奏」节。

**波形：前高 → 中稳 → 尾情感峰**（以 40 集免费剧为例）：

| 阶段 | 集数区间 | 强度 | 密度与硬规则 |
|---|---|---|---|
| 爆点前置段 | 第 1-3 集 | ★★★★★ | **每集≥1 硬爽+集尾钩，零铺垫债**；三集内立完主角困境/金手指/主 CP |
| 第一幕主战 | 第 4-10 集 | ★★★★ | 每集一爽；**全剧最强打脸放第一幕收官**（E9-10 量级位），蓄力在幕内完成 |
| 中段持稳 | 第 11-30 集 | ★★★ | 每 2-3 集一爽，可降不断供；换挡糖钩/关系推进，同时给尾段埋情感线 |
| 尾段情感峰 | 第 31-40 集 | ★★★★（情感向） | 几乎每集有爽；**峰值是情感揭晓/团圆/告别，不是力量打脸**——尾段职责＝给追到底观众的情感回报，力量清算放尾段前部 |

- **零铺垫债 ≠ 无压白给**：前置段硬爽用当集压-放微循环（当集建压、当集释放，如当众谎言当场戳穿）——"压抑越深释放越爽"不作废，只是蓄力周期从跨十几集压缩到集内/幕内，铺垫债后偿。
- **第一幕＝全剧最重要战区**：人物、金手指、反派恨度、CP 脸全在前 10 集立住，建置本身用爽点完成（开局名场面既是建置也是爆点），不另占慢集。

## 节奏调控工具

### 加速节奏的手段

| 手段 | 效果 | 使用场景 |
|------|------|----------|
| 短场次快切 | 增加紧迫感 | 追逐/对峙/倒计时 |
| 多线交叉叙事 | 增加信息密度 | 阴谋即将败露 |
| 对话加速 | 提高紧张感 | 争吵/揭露/质问 |
| 倒计时设置 | 制造deadline | 营救/拆弹/赶路 |
| 连续反转 | 打破观众预期 | 高潮段 |

### 减速节奏的手段

| 手段 | 效果 | 使用场景 |
|------|------|----------|
| 双人对话场景 | 情感深入 | 感情线推进 |
| 独处/回忆 | 角色内心展示 | 低谷/转折前 |
| 日常生活片段 | 呼吸感 | 大高潮后 |
| 风景/环境描写 | 氛围转换 | 场景转换 |

### 使用原则

```
加速:减速 比例（按阶段）:
├── 起势段: 6:4（稍快）
├── 攀升段: 7:3（持续加速）
├── 风暴段: 8:2（极速，仅在高潮间短暂喘息）
└── 决战段: 9:1（前段极速）→ 3:7（结局减速收束）
```

## 节奏自检方法

写完每5集后，回顾检查：

```
节奏自检清单：
├── 这5集的情绪曲线是否有起伏？（不能一直平/一直高）
├── 每集是否已明确标记「压」或「放」（无中间态）、打了 1-10 强度？连成 K 线是否单调？
├── 是否有连续 3 集以上的「压」而不放？（情绪疲劳风险）
├── 每集是否都有至少1个新信息或新进展？
├── 有没有连续2集以上的"信息真空"？
├── 高潮点之间的间隔是否合理？（不超过5集）
├── 喘息段是否也在推进剧情？（不能只是闲聊）
├── 整体走势是否符合当前阶段的节奏特征？
└── 观众在任意一集退出，是否都会有"未完成"的感觉？
```

**致命节奏问题：**
- ❌ 连续3集以上无实质性剧情推进 → 观众弃剧
- ❌ 高潮之间间隔超过8集 → 观众失去耐心
- ❌（模型 A·付费）全剧最高潮出现在非最后阶段 → 付费段后续乏力
- ❌（模型 B·免费）前 3 集没有硬爽、最强打脸压到尾段 → 大多数观众流失在爆点之前
- ❌ 结局拖沓超过3集 → 观众觉得注水

## 实证补编 · 124 部真实爆款回采（2026-06-09）

> 来源：`shortdrama-structure-mastery` 工作流逐本结构重读 122 部竖屏爆款短剧 + 2 PDF → 124 张结构卡（实证语料 `scard_NNN` 可回溯·语料未随本包分发，在源库 craft/_research-structure-corpus/）。【新增】=文件原本没有；【校准】=对现行某条的修订注记；【印证】=真实爆款给的背书。每条配《天才足球少年》(校园体育热血逆袭)落地写法。

### 1.【校准】压段≤3集、放段≤2-3集双向阈值；放必须"物质化"（动作/事件/命运），禁口头胜利

现行只约束"连压≤3集"（单向）→ 应补对侧：**放段也有上限（≤2-3集，放太久=失张力）**，并立硬判据"放段释放必须可见化"。

- `scard_121`（《闪婚老公是豪门》）"节奏铁律"原文「**压段不超过3-5集，放段不超过2-3集，循环往复**」+「放段释放必须是具体可见的胜利」：第7集战北霆当场踢飞刘总+废其右手(动作)/第27集司情2小时让林大为被警察带走+当众宣判(事件)/第69集把监视司情的沈婉清"扔非洲"(命运)——无一是"我会让你后悔"的口头胜利。
- `scard_005`（《封总的复仇娇妻》）例外条款：常规"从不连压超3集"，**唯一例外第35-37集连压三集险境**(被骗→下药→被堵)用在第一轮高潮点，随后第38-40集立刻给最大释放。即**连压满3集只许在阶段性高潮用一次**。`scard_002`（《紫菀·深宫逆袭记》）更绑死奇偶位（奇压/偶放）。
- **落地**：每集打"压/放"标签+1-10强度连成K线；凌川被压最多连3集，第3集必给可见小放(神级触球/助攻)，禁"教练点头表扬"口头放。

### 2.【校准】一事一集：封顶 1-2 条信息、禁开两条独立新线（按集尺分档）

现行"单集至少1个新信息/不能信息真空"方向只对一半 → 应改为"**封顶1-2条、一事一集、禁开两条独立新线**"，补对侧禁忌"信息过载"(1分钟竖屏真问题不是信息少，是观众跟不上)。

- `scard_002`（《紫菀·深宫逆袭记》）最狠「**每集一件事，不交叉。这是1分钟短剧的铁律——信息过载=观众跟不上=划走**」；`scard_044`（《危机四伏》）"严格一事一集"：第3集只做看房决定/第4集只做看房行为/第5集只做搬入+反派首现。`scard_074`（《护国战神：征战钓鱼岛》）实测「没有一集同时推两条独立新线，一集=一个情绪落点」。
- **分档例外**：`scard_120`（《长公主在上》，古装权谋~1分钟/集）反而「**几乎没有一集只推一条新线**，同时推男女关系线+政治线各一步，两线交替剪辑信息密度倍增」。判据=集尺：1分钟纯竖屏→严格单线；1.5-2分钟权谋/群像→可双线交替但**每线只走半步**。
- **落地**：每集只承载一个足球叙事事件(一场对抗/一次训练突破/一次身份误解)，情感副线只附带不主导。

### 3.【校准】微型三幕 1 分钟精确版：承(0-15s,解上集钩)→冲(15-45s,单一主事件+1转折)→断(45-60s,将揭未揭硬切)，配比≈1/4:1/2:1/4

### 4.【校准】情绪弹簧补两个尺度：集间"谷→小峰→大峰"三连弹 + 单集内泄压节拍

现行弹簧只当"集级压放" → 应补：① 三连弹"谷→小峰→大峰"(压越深释放越甜，用于关系升温)；② **单集内泄压节拍**(高压段插一个喜剧/日常beat打断再拉起，1分钟剧尤其关键)。

- 三连弹：`scard_120`（《长公主在上》）第18集公主掐脖逼问+罚跪一夜(极压谷)→第19集亲手阻止徐子俊欺负顾玄清(小峰)→第20集上药→暧昧→床戏(大峰)，原文「**压强越大释放越甜**」。

- **落地**：关键比赛走三连弹(上半场被压→中场被看见→下半场绝杀)；高强度对抗beat后插队友日常喜剧beat再拉回紧张。

### 5.【新增】竖屏建置压缩术：零旁白，"反派嘴倒灌 + 道具替代 + 行动暴露 + 当事人疑问"四件套，把前史拆给多人吵着带出

用户点名焦点，现行文件完全没有。124卡标准答案——**绝不用独立人物介绍段/旁白交代前史，全部碎片化嵌进冲突对白**。

- **反派嘴倒灌**：`scard_117`（《重启》）「前史不用闪回，**用反派台词倒灌**」(白雪娇毒独白"当初甩掉徐千意那糟糠之妻可比谁都快活"=前史)；`scard_004` 反派黑历史全靠对白"炫耀式供认"。

- **整合公式（拆给多人吵着带出）**：把一段本该旁白的前史拆成几句带情绪的冲突台词分给在场不同角色——施害者炫耀(主角受过什么屈)+主角反呛(立场)+旁观者起哄(社会评价)。一场争吵30秒同时完成"建置+羞辱蓄力+关系定义"。`scard_042`（《豪门弃女逆袭记》）「外形判断全部借反派嘴说出(双重功能:建置+羞辱)」即此。**三禁忌**：禁旁白交代前史/禁独立人物介绍段/禁第一场原地踏步铺背景。
- **落地**：第1集球场边一场吵架带出凌川前史(嘲讽者交代"野路子/瘸过腿"+凌川反呛+看台起哄)；一只旧球/旧伤疤1秒建动机；不经意颠球让观众自己推断"这人是高手"。

### 6.【新增】卡点付费 = 商业结构位，固定落"危机最高点/最强耻辱点/情感谷底+救援未到"那一帧，免费段(前~10集)末硬切

1分钟竖屏小程序剧特有商业节奏锚，现行只字未提，却直接决定免费段如何蓄力。124卡卡点几乎全押第6或第10集。

- **危机最高点+救援未到**：`scard_038`（《民国浪荡子》）第10集「壮汉围住曹若梦即将强暴=收费节点」，立规则「**付费墙必须设在危机最高点+救援未到的一帧**」；`scard_034`（《我在灵异客栈值夜班》）第10集「304不存在+回家退路断→付费墙绝境」。

### 7.【新增】反派"养肥账单"是节奏蓄力器：每集存 1-2 条可量化弹药，打脸统一结算，养肥时长按级别分档
