# 逐场审计手册（剧本医生层）

> **定位**：L3 大纲 / L4 分集 / L5 单集**出稿之后**的诊断透镜——不是创作流程，是审计工具。
> 与其余 8 篇的关系：那 8 篇管「怎么写出来」，本篇管「写出来的站不站得住」。
> 与制作层的同构：本篇的剧情因果链 ↔ S4 分镜表接点行（上承/下交）——**剧本级「因为」链是镜级接点链的上游**，
> 剧本层因果断了，分镜层接点写得再好也接的是断戏。
> 来源：DeepWhite screenwriting v1 的 screenwriter 审计引擎（麦基 Scene Value / 因果审计 / 亚里士多德删场测试通论），
> 2026-06-12 按本仓体例重写＋竖屏短剧适配。

## 1. 因果性审计（「因为」不是「然后」）

逐场问一个问题：

```text
第 N 场发生，是因为第 N-1 场发生了什么？
```

答得出＝因果链；只答得出「然后就到了这场」＝糖葫芦串（事件并列无推动）。好结构每一场都是上一场的**结果**，
同时是下一场的**原因**。竖屏短剧因果链要求比长片更狠——观众划走只要 1 秒，「然后」场就是划走点。

诊断时给问题场打标签（与分镜表败因标签同思路，开放可增）：

| 标签 | 含义 |
|---|---|
| `[因果]` | 这场不来自上一场的结果（换掉上一场它照样成立） |
| `[价值]` | 这场没有价值转变（见 §2） |
| `[人物]` | 行为不符合人物欲望/缺陷/前史（对照 CHAR 卡） |
| `[世界观]` | 与设定或已公开信息冲突（对照圣经/世界观档案） |
| `[节奏]` | 过长/过短/信息重复/密度失衡（对照 rhythm-curve） |
| `[台词]` | 直白/解释/AI 腔（转交 dialogue-naturalism 两道 linter，本篇不重复管） |

## 2. 场景价值转变（每场必须有一根杠杆被扳动）

每场回答四问：

1. 这场**开始**时，哪个价值处于什么状态？
2. 这场**结束**时，它变成什么状态？
3. 是正转负，还是负转正？
4. 是**哪个动作**造成转变？（答不出动作＝转变是旁白送的，不算）

常见价值对（短剧高频在前）：

- **知晓/无知**（隐藏信息差的逐场账——本仓剧情引擎「信息差×分层打脸」的场级刻度）
- **身份（隐藏/暴露）**、**强弱（碾压/反制）**、**债（欠/清）**——爽点型价值对
- 控制/失控、信任/背叛、希望/绝望、自由/束缚、爱/占有——文戏型价值对

**没有价值转变的场＝废场或过渡场。** 长片能容三五个过渡场，竖屏短剧一个都贵——
要么并进相邻场，要么给它装上一根价值杠杆。

**删场测试**：把这场删掉，结局会变吗？后续场次的因果链断吗？都不会→删或并。
（亚里士多德行动统一律的实操版；对应 rhythm-curve 的「无效情节」检查，但本条给了可执行的判据。）

**疏密并排检（指纹 F10）**：单场各拍并排列新信息点数——拍拍相同＝信息密度均匀，没有一拍是「事件」（逐拍检查抓不到，只在并排看时显形）；集级配套查 F11 代价即时结清。判据正本＝《审计-台词AI指纹-20260820》（源库文档，不随本包分发） §三.5，本篇 `[节奏]` 标签的「密度失衡」以它为细则。

## 3. 单集诊断评分表（10 分制 · 锁版前剧本医生 pass 用）

竖屏短剧单集七维（按本仓管线适配，开篇集加权「开场钩子」）：

```text
开场钩子：/10        （前 3 秒画面有没有事——对照 opening-rules 黄金5秒）
场景因果：/10        （§1 逐场过，「然后」场计扣）
人物主动性：/10      （主角在做选择，还是被设定推着走）
价值转变密度：/10    （§2 逐场过，废场/过渡场计扣）
台词克制：/10        （有没有解释设定/解释情绪/点题——转 dialogue 两 linter 结果汇总）
结尾钩子：/10        （对照 hook-design 五钩型 + 停在「已知未说」）
节奏密度：/10        （过满或过空——对照 rhythm-curve 压/放与情绪K线）
```

输出格式（诊断报告固定五段）：

```text
【整体判断】一到三句，先说底子。
【量化评分】七维分数，每分一句理由。
【主要问题】带 §1 标签的问题场清单。
【修改优先级】见下。
【下一步】先改哪一项。
```

**修改优先级**（高→低，分数低但不伤主线的放后面）：

1. 因果断裂（`[因果]` 场）
2. 主角没有主动选择
3. 无价值转变的场
4. 开场不抓人
5. 结尾无钩或无余味
6. 台词解释设定
7. 节奏过满或过拖

⚠️ 分数是定位问题的，不是评判作者的——不要用分数压倒创作判断；
与导演品味档案的「改动率」指标互补（评分定位问题 → 用户改稿 → 回采进品味档案）。

## 4. 用法（接管线）

- **L3 大纲锁版前**：对大纲跑 §1 因果链（集与集之间同样适用：第 N 集因为第 N-1 集）。
- **L4 分集锁版前**：逐集跑 §2 价值转变（每集至少一次主价值翻转）＋ hook 衔接。
- **L5 单集出稿后**：完整跑 §3 七维评分，报告交用户 gate；`[台词]` 问题转 dialogue-naturalism + T1-T10 二遍 linter。
- **改稿纪律**（screenwriter 工作纪律保留）：只改用户点名的范围，不顺手优化相邻内容；
  用户说「不对」先问一个窄问题（例：「这场里，主角是想保护对方，还是利用对方？」），再给**一个**新版本，不给多备选。

## 质量自检

- [ ] 每场都答得出「因为上一场……」？
- [ ] 每场都有进/出价值状态＋造成转变的动作？
- [ ] 删场测试跑过、过渡场清零或给出保留理由？
- [ ] 主角的关键节点都是主动选择？
- [ ] 评分报告给了修改优先级而不只是分数？
