# 台词与动作可视化法则

写作层 **L5（单集剧本）** 的 line-level playbook。craft/ 其余 6 篇管**结构**（题材 / 反派 / 节奏 / 爽点 / 钩子 / 开场），这一篇管**落到纸面的每一句台词和每一行动作怎么写**——是结构骨架之上的"肌肉"。题材无关，写每句台词/动作前对照。

> 一句话立场：**短剧剧本是写给摄像机看的说明书，不是写给读者看的小说。** 文学才华在这里是负债——台词只为传递信息与制造冲突，动作只为让镜头有东西可拍。

> ⚠️ **配对篇 `dialogue-naturalism.md`（去 AI 味）必须同读**：本篇管「**说什么 / 功能**」，但「功能 ≠ 直白」。把下面法则一「信息前置」推到极端、让角色把身份/动机/评价/主题直接说出口，恰恰生产**最重的 AI 味**（程西安「又是个内心被困住的孩子啊」、江晚「你是有足球天赋的」都是这么来的）。**信息前置是对观众说的**（钩子/反转直给）；**角色对角色说话要走潜台词**——怎么把功能写得像真人脱口而出而非 AI 念稿，归 `dialogue-naturalism.md`。两篇是骨与肉，配对过 linter 才算定稿。

---

## 法则一：信息前置，废话后置

短剧台词是**功能性**的：首要任务是抛身份、抛冲突、抛目标，不是寒暄、不是含蓄、不是铺垫情绪。

- **第一句就抛核心**：身份 / 冲突 / 目标用最直白的话第一时间砸出来，不绕弯。
- **一句能说完，绝不用两句**；能用一个词，绝不用一句。
- **消灭闲聊**：删光"你好吗""最近怎么样""好久不见"这类零信息对白——它们在长剧是呼吸，在短剧是注水。

**对照（错 → 对）：**
```
✗ 文学写法（7 句寒暄垫场，0 信息）
  男：你好，好久不见。  女：是啊，好久不见。
  男：你最近怎么样？    女：还行吧。
  男：听说你要结婚了？  女：嗯。  男：恭喜。  女：谢谢。

✓ 短剧写法（1 句，信息+冲突同时落地）
  男：（直接掏出请帖）我结婚了，下周。
  女：（瞳孔一缩，手指收紧）……恭喜。
```

## 法则二：潜台词动作化

角色的"潜台词 / 内心戏"不要让演员去"演"出来，更不要写成旁白或心理描写——**翻译成一个看得见的动作或身体反应**。竖屏短剧没时间也没景深给细腻表演，情绪必须被身体放大。

| 内心状态（别直接写） | 动作化（这样写） |
|---|---|
| 他很愤怒 | 拳头砸在桌上，水杯震倒，水洒一桌；额角青筋暴起 |
| 她很伤心 | 眼眶发红、嘴唇发抖，眼泪砸在手背上，转身用袖子一抹 |
| 他震惊 | 手里的咖啡喷出来 / 文件"啪"地滑落在地 |
| 她在隐忍 | 指甲掐进掌心，笑着却把酒杯捏到发白 |
| 他暗藏身份 | 被嘲讽时只是低头道歉，**眼神一凛**（一个反差特写就够） |

**情绪 → 戏剧化外部动作**（强冲突场可直接调用，记忆点最深）：
`耳光 / 下跪 / 磕头 / 泼水 / 掌嘴 / 撕请帖 / 摔文件 / 单膝跪地 / 90°鞠躬`。这些"夸张的、可拍的、一眼读懂"的动作，就是短剧的视觉货币。

## 法则三：动作可视化（动词 > 形容词）

剧本正文（非台词部分）用**动词和短句下指令**，把"形容词 + 情绪描述"换成"动作指令"，让导演/演员/出图模型一看就知道**镜头里发生了什么、该拍什么**。

**对照（错 → 对）：**
```
✗ 男主非常生气，眼神凶狠地看着反派。        ← 形容词，无可拍动作
✓ 男主一把揪住反派衣领，将他狠狠撞在墙上。
   男主：（咬牙）你敢再说一遍？             ← 动词链，镜头有抓手

✗ 她看起来很害怕，不知道该怎么办。
✓ 她后退半步，背抵住墙，手在身后摸索门把手。
```

**画幅构图预设**：写动作时就预设本项目立项时拍板的画幅（见 `项目档案/世界观.md` 的 `画幅` 字段）。**竖屏 9:16**——上半身特写、快剪、单主体入画；少写群像调度（竖屏装不下），多写"谁的手 / 谁的脸 / 谁的一个动作"的特写点。**横屏 16:9**——可用中景与双人同框，环境信息进画面，群像调度成立；但动作仍要具体到人，不写"众人纷纷议论"这类无主体调度。这一条与出图/分镜规范同源（剧本写得越"可视化"，下游 S4 分镜表 / S5 静态控制帧越好落）。

## 法则四：一句台词一个功能（短剧 = 对白驱动·密度≠空喊）

每句台词必须**推动情节**或**塑造人物**，二者至少占一个；都不占的删掉。对白节奏要快——争吵、质问、揭露场尤其要短促交锋，不要让任何一方说"完整的一段话"。

**⚠️ 短剧是对白驱动·别走电影式沉默画面叙事。** 短剧服务**碎片观影**（观众边干别的边看手机、光听声音也要跟得上）——所以**画面里发生的事、一个角色多强、局面多危险、情绪张力，都要有人「说出来」**，不能像电影那样靠纯画面/沉默镜头讲。这跟法则三「动作可视化」不冲突：△ 写给摄像机（可拍的动作），**对白替半屏观众把戏讲明白**（密度驱动）。例：门将神扑，不能只给一串扑救画面无声闪过——要有人喊出来这球多险、他多神。

**⚠️ 但「密度」≠「空喊」——这是最容易踩的填充陷阱。** 堆一串没功能的惊呼（「神了！」「这都扑到了？！」「哇——」「开挂了吧」）**看着热闹、其实零功能 = AI 填充**，比没台词更糟。正解 = **每句口播都用 setup→payoff 结构挣到功能**：

> **对手先装逼「这球我进定了」→ 主角化解 → 那句装逼当场被打脸。**

这一句「进定了」就同时办了三件事：递信息（这球很险）、立人物（对手狂）、挖坑等打脸（payoff）——且**可证伪**（他说进、结果没进 = 爽点落地，呼应 `satisfaction-matrix`「爽感 ∝ 反派蠢话」「爽点必须可证伪」）。比一句旁观者「好险啊」强十倍。**门将 showcase 范式**：每个扑救前让对手先狂（「就这？」「进了！」「门给我让开！」「神仙也扑不到！」）→ 扑出 → 打脸冻在原地。

**口播台词的功能清单**（每句对号入座，对不上就删）：挖坑等打脸 / 递关键信息 / 立人物（狂、怂、痴、稳）/ 推进利害（"再来一波就丢了"）/ 立 flag（等翻车）/ 关系转向（被实力折服）。

**⚠️ 反应人物要归位——写谁说话前先核 ta 此刻在哪、在干嘛。** 别图省事把任何人都当解说员。**在场比赛的球员只给即时拼抢喊话**（"顶住！""盯死他！"），**不做观众式解说**（"哎呀他这是第几个扑救了"）；旁观式惊呼/质疑归**替补席 / 场边教练经理 / 看台观众**。落笔前查角色卡（谁首发谁替补、此刻在场上还是场下），写错位置 = 穿帮。

## 分题材：台词调性参考行

原则题材通用；**语气**按本剧题材取对应行（别套错腔）：

| 题材 | 主角台词调性 | 反派台词调性 | 典型句式 |
|---|---|---|---|
| 战神 / 逆袭 | 短、冷、不解释 | 嚣张、轻蔑、目中无人 | 主「不劳你费心。」 反「你也配？」 |
| 霸总 / 甜宠 | 不容置疑的宠溺 / 占有 | （第三者）酸、刺、试探 | 「从今天起她是我的人，动她一根头发试试。」 |
| 重生 / 复仇 | 平静下藏杀机、信息密度高 | 自得、步步紧逼 | 「这一世，该你跪了。」 |
| 悬疑 / 探案 | 克制、留扣、问句多 | 伪善、话里有话 | 「你怎么知道她死在几点？我没说过。」 |
| 古装 / 宫廷 | 绵里藏针、敬语裹刀 | 阴柔、捧杀 | 「娘娘说的是，臣妾记下了。」 |
| 校园 / 青春 | 直、莽、口语化、半句噎住 | 高傲、群嘲 | 「我不会。」（短促、不辩解） |

> ⚠️ 与角色音色库联动：台词写定后，下游 S6 按"说话模式"选嗓——口语句用口语样本、内心 VO 用 VO 样本（见 `feedback_s6_node_build_conventions` / `feedback_motion_only_prompt`）。台词文本本身要**精准到字**，下游直接拿去 lipsync。

## 写完自检表（L5 出稿后逐条过）

```
台词 / 动作自检：
├── 有没有零信息寒暄？（你好吗 / 最近怎么样 / 好久不见）→ 删
├── 每句台词是否都在「推进情节」或「塑造人物」？都不占 → 删
├── 有没有零功能的空喊填充？（神了 / 这都行 / 哇 / 好险）→ 改成 setup→payoff（对手先装逼→被打脸）或删
├── 比赛 / 动作 / 高光戏：画面里发生的事、谁多强、局面多险，是否有人「说出来」？（短剧对白驱动·别沉默画面叙事）
├── 每个反应台词的说话人，此刻位置对吗？（在场球员只即时喊话·旁观归替补席/场边/看台·查角色卡别穿帮）
├── 第一句是否直接抛了身份 / 冲突 / 目标？还是在垫场？
├── 内心戏 / 潜台词是否已翻译成可拍的动作或身体反应？（没有"他很X"裸写情绪）
├── 正文是否动词链 + 短句下指令？（无"非常生气""凶狠地"这类形容词替代动作）
├── 本集情绪峰值处，有没有一个"夸张可拍"的外部动作做记忆点？（耳光/下跪/泼水…）
├── 动作是否按本项目画幅预设？（9:16：上半身特写/快剪/单主体，非群像大调度；16:9：中景/双人同框可用，但动作具体到人）
└── 台词调性是否对上本剧题材横表行？（没串腔）
```

> ✅ 过完本表，再过 `dialogue-naturalism.md` 的「AI 味七宗罪 linter」——**本表保「不迷路」（功能/可拍），那张保「不像 AI」（真实/潜台词）**，两张都过台词才定稿。

**致命台词问题：**
- ❌ 整场戏全是"完整段落"对白、无短促交锋 → 节奏垮、出不来冲突
- ❌ 用旁白 / 心理描写交代本可用动作呈现的情绪 → 镜头空、演员没东西演
- ❌ 形容词堆砌（"他愤怒地、凶狠地、咬牙切齿地…"）却没有一个具体动作 → 下游出图/分镜抓不到画面
- ❌ **比赛 / 动作戏只给一串画面无人说话**（电影式沉默叙事）→ 半屏观众跟丢，短剧要对白驱动
- ❌ **靠空喊堆"密度"**（"神了！""这都扑到了？！""哇——"）→ 看着热闹零功能 = AI 填充；改 setup→payoff（对手装逼→被打脸·可证伪）
- ❌ **反应台词张冠李戴**（让在场踢球的球员当解说员 / 把场上人写成替补席旁观）→ 穿帮；落笔前核角色此刻位置
