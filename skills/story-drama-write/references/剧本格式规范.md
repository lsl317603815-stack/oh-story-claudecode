# 短剧剧本格式规范

> 单集剧本（L5）正文的强制输出格式。**真相源＝在制剧本的真实通行写法**（源库 ZQSN E005–E025 锁版件实证）。源库配有 `drama_core` 机审包（`parse_script_scenes` / `validate_episode_script` 等），**该包不随本包分发**——本包内这些校验一律按第五节「落稿自查」逐条人工过，不得声称跑过机审。#镜号/机位/分镜留给下游分镜环节。

## 一、文件结构

1. **frontmatter（YAML）**：`type: episode_script`、`project`、`episode: E<NNN>`、`season`、`title`、`version: v<N>`、`status: draft|locked`、**`aspect_ratio`**、`scene_count`、`narration_density`、`duration_estimate`、`based_on`、`continuity_from`（上集结尾承接一句）、`ending_state`（本集结尾状态一句）、`locked_at`、`revision[]`（逐版一行）；锁版件另有 `source_revision_sha256`（由锁版流程写入）。**正文>meta**：正文与梗概/字段冲突认正文。
2. **画幅字段 `aspect_ratio`（必填，每集都写）**：取 `9:16`（竖屏）或 `16:9`（横屏），**必须等于立项采访拍板、记在 `剧本/{项目名}/项目档案/世界观.md` `画幅` 字段里的值**。缺这个字段或与立项值不一致的剧本＝格式不合格，不许进锁版。它不是标注，是**写法开关**：竖屏走上半身特写/快剪/单主体，群像调度装不下；横屏可用中景与双人同框，环境信息进画面（落法见 `references/craft/dialogue-action.md`「画幅构图预设」）。一个项目中途改画幅要重过立项采访，不在单集里改。
3. **标题行**：`# 第X集《标题》`。
4. **视觉锁引用块**（文首 `>` blockquote，可选）：全集光调/场景范围/服装口径等制作约束——**不混进场次正文**；画幅归 frontmatter 必填字段，不靠这里；更细的制作锚点写文末 `# 制作附注`。

## 二、场头（机器接口·一行式）

```
场次：X-Y 时间：<日/夜/晨/傍晚…> 环境：内/外 地点：<具体场景> 出场人物：<A、B、C>
```

- 行首认 `场次：N-M`（半角/全角冒号均可）；**同集场序必须 1..K 连续，不缺不跳不重**（落稿自查硬条，见第五节）。
- 换场、时间跳跃、闪回独立成场时，起新场头。
- 出场人物全名、全文统一、按重要性排序；群戏可写「南城众」「群众若干」；出场人物须 ∈ 人物索引（群体/系统声源豁免）。

## 三、正文写法

- **动作行**：`△　<镜头能拍到的动作/表情/调度>`——可拍摄语言：删文学性内心与比喻；外观归 CHAR 卡，正文不重复描写。
- **台词**：`角色名：台词`；语气/神态提示：`角色名（提示）：台词`。
- **心理活动/内心独白**：`角色名(OS)：内容` 或 `角色名(语气OS)：内容`；**画外音**：`角色名VO：内容`（未出场角色/画外声源；群体写 `群众VO：（位置提示）内容`）。
- **闪回**：另起一行「闪回」，结束标「闪回结束」；短暂回忆写「插入镜头」；长回忆建议独立场次。
- **字幕/空镜**：`【字幕：内容】` / `【空镜：场景描述】`——与场景内容紧密关联（比赛时间推进常用 `【字幕：上半场第X分钟】`）。
- 动作段/台词行之间空一行（markdown 渲染需要，不影响格式判定）。

## 四、边界与路由

- **#镜号 / 机位 / 运镜 / 逐镜景别不写进剧本**——那是下游分镜的活。
- **lipsync 路由**：`(OS)` / `VO` / 暗处画外 / 气声自语 = 非 lipsync（下游走内心/画外/气声音色）；其余为 lipsync 同期声。
- 台词精简有力；短剧＝对白驱动，画面的事必须说出来——台词写法正典见 `references/craft/`（dialogue-action / dialogue-naturalism / dialogue-protocol）。

## 五、落稿自查（原机审的人工替代·逐条过，过不了不许锁版）

本包不带 `drama_core`，以下每条自己数、自己核，不许写「机审通过」：

1. **场序连续**：从头数场头 `场次：N-M`，M 必须 1..K 连续，不缺不跳不重。
2. **出场人物入索引**：每个场头的出场人物逐个对 `剧本/{项目名}/角色总库/人物索引.md`，群体（南城众/群众若干）与系统声源豁免。
3. **发声主体入索引**：正文每个 `角色名：` / `(OS)` / `VO` 的说话人同样对索引。
4. **画幅**：frontmatter 有 `aspect_ratio`，且等于 `项目档案/世界观.md` 的 `画幅`。
5. **frontmatter 齐全**：第一节必填字段一个不缺；`scene_count` 等于实数出来的场数。
6. **边界**：全文搜不到 `#镜号`、机位、运镜、景别词。

## 示例片段（按真实锁版件形态）

```
---
type: episode_script
project: 南城十号
episode: E025
title: 南城十号
version: v1
status: draft
aspect_ratio: "9:16"
scene_count: 1
---

# 第25集《南城十号》

> 第一季季终·锁版正本

场次：25-1 时间：日 环境：外 地点：东南大区预选赛球场·中圈 出场人物：凌川、文一帆、高远、沈渊、江晚、南城众

△　全场结束哨的余音还压在球场上。电子比分牌定格在"南城 2:2 东海"。

高远：凌川学长！你那个倒钩真是太绝了！

△　高远第一个扑上来抱住凌川，队友们紧跟着压上去。

凌川(OS)：原来被人接住，是这种感觉。

群众VO：（看台低语）南城这队，今年不一样了……

【字幕：终场】
```
