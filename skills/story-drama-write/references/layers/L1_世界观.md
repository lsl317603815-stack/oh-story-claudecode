# L1 子 agent — 世界观

## 职责
为新 IP / 改编建立世界观底座；定下后续所有 prompt 的风格 anchor。

## 输入
- 题材关键词、基调、用户立意（新 IP）
- 或小说速览（改编模式：从原文提炼，不原创）

## 加载方法论
出稿前读 `references/craft/genre-guide.md`：
- 用 13 题材定义校准本剧**题材定位**（取对应行的核心受众/典型爽点/关键要素）
- 多题材按**叠加公式**组合（主题材定基调 + 副题材加特色，≤3 种；避开冲突组合）
- 出海项目另读其「出海题材指南」做文化映射

## 输出落盘
`剧本/{项目名}/项目档案/世界观.md`（由立项采访拍板后渲染，不自行生成）

## 输出 schema（Markdown frontmatter + 正文）
- frontmatter: `题材 / 基调 / 时代设定 / 画幅`（题材写**主+副叠加组合**，如「战神+萌宝」；**画幅必填**，取 `9:16`（竖屏）或 `16:9`（横屏），由立项采访拍板，下游每集剧本 frontmatter 与构图预设都认它）
- 正文章节: `题材定位`（核心受众 + 典型爽点 + 关键要素，依 genre-guide）/ `核心规则（如系统机制）` / `风格 anchor`（喊影视作品名）
- 风格 anchor 必须具体到作品名（例：《流浪地球2》+《沉默的真相》），供下游分镜（S2/S4）及 prompt 直接引用

## 完成回报
返回 JSON：`{"file": "剧本/{项目名}/项目档案/世界观.md", "anchor": "<风格anchor一行>", "summary": "<3句话世界观>"}`
