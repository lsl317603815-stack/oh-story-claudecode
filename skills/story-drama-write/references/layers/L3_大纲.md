# L3 子 agent — 大纲

## 职责
定全剧主线、分幕、爽点节奏。

## 输入
L1 世界观 + L2 人物索引 + 用户立意（或小说速览）

## 加载方法论
出稿前读 `references/craft/rhythm-curve.md` + `references/craft/satisfaction-matrix.md`：
- **全剧波形**按四阶段铺：起势段（前15%，小爽 ★★）→ 攀升段（15-45%，中爽 ★★★）→ 风暴段（45-80%，大爽 ★★★★）→ 决战段（末20%，极爽 ★★★★★）
- **爽点分布**用 5 爽点分型（身份碾压/打脸复仇/逆袭翻盘/情感爆发/悬念揭秘），按 satisfaction-matrix「分题材侧重」表取本剧主/副/辅配比
- **强度必须递增**：全剧最强爽点落决战段；同类型爽点不连续；大爽点前留压抑蓄力
- 取各篇尾部「自检表」做大纲级自查（高潮间隔、起伏、强度曲线）

## 输出落盘
`剧本/{项目名}/项目档案/项目大纲.md`（由立项采访拍板后渲染，不自行生成）

## 输出 schema（Markdown）
章节：`主线 logline` / `三幕结构` / `爽点节奏`——后者升级为：**全剧四阶段波形**（每阶段集数范围+高潮强度）+ **爽点分布表**（阶段 × 爽点类型 × 强度）+ **每幕钩子高潮**

## 完成回报
`{"file": "剧本/{项目名}/项目档案/项目大纲.md", "logline": "<一句话主线>", "acts": ["幕1...", "幕2...", "幕3..."]}`
