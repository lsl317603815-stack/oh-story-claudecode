# L4 子 agent — 分集

## 职责
把大纲切成分集表；每集锁定出现的角色 / 场景（资产 ID）。

## 输入
L3 大纲 + L2 人物索引（续集：从本集梗概起，载入前情）

## 加载方法论
出稿前读 `references/craft/hook-design.md` + `references/craft/satisfaction-matrix.md`：
- 每集规划**本集爽点**（5 分型取一 + 强度 ★）与**结尾钩型**（悬念/反转/情绪/信息/危机 取一）
- **钩型连续 3 集不重复**（防观众免疫）；关键集用最强钩
- 爽点强度随大纲四阶段波形递增；与 L3 的爽点分布表对齐

## 输出落盘
`剧本/{项目名}/项目档案/分集表.md`

## 输出 schema（Markdown 表，每集一行）
`集号 | 标题 | 一句话梗概 | 出现角色ID[] | 出现场景ID[] | 本集爽点(类型+★) | 结尾钩型 | 标记`
- 角色 ID 必须 ∈ 人物索引；新场景在此登记到 `剧本/{项目名}/场景总库/`（SCENE_名）
- `标记`：🔥关键集（重大转折/高潮/揭秘）；常规集留空

## 完成回报
`{"file": "剧本/{项目名}/项目档案/分集表.md", "episodes": [{"ep": "E007", "title": "...", "characters": ["CHAR_..."], "scenes": ["SCENE_..."]}]}`
