# L2 子 agent — 人物（可 fan-out：每角色一个 agent）

## 职责
为每个角色建一张人物卡；外形段落要可直接喂图像模型。

## 输入
- L1 世界观 + 该角色的定位（主/反/配）
- 续集：已有 `剧本/{项目名}/角色总库/` 里的旧角色卡（复用，不重建）

## 加载方法论（角色定位含「反」时）
出稿前读 `references/craft/villain-design.md`：
- 反派按**四层体系**反推定位：小反派（炮灰/前期靶子）→ 中反派（主要对手）→ 大反派（终极 Boss）→ 隐藏反派（反转用，非必需）
- 每个反派回答三问：动机（为何作恶）/ 支撑（实力从哪来）/ 节制（为何不更早下手）——确保**可恨 + 可信 + 递进**
- 隐藏反派必须埋 **≥3 处可回溯伏笔锚点**（起势/攀升/风暴各一），无伏笔的反转是败笔
- 台词风格按层分化（小反派嚣张直白 / 大反派从容高位 / 隐藏反派揭露前后 180°）

## 输出落盘
- 每角色：`剧本/{项目名}/角色总库/<CHAR_名>.md`
- 索引：`剧本/{项目名}/角色总库/人物索引.md`（资产ID ↔ 姓名 速查表，主控汇总写）

## 输出 schema（每卡 Markdown frontmatter）
`资产ID（CHAR_名）/ 姓名 / 角色定位 / 重要度 / 外形 / 性格 / 关系 / 出场集[]`
- **外形**段落 = P2 角色生图的直接 prompt 输入，写实、含发型/脸型/体型/标志性服装/年龄
- 重要度是属性字段，**不进 ID**（ID 永远是 CHAR_名）
- **反派卡**额外写：`反派层级`（小/中/大/隐藏）+ `核心动机` + （隐藏反派）`伏笔锚点[]`

## 完成回报
每 agent 返回：`{"asset_id": "CHAR_李然", "name": "李然", "file": "剧本/{项目名}/角色总库/CHAR_李然.md"}`
