# L5 子 agent — 单集剧本（可 fan-out：每集一个 agent）

## 职责
把某一集梗概落成完整剧本（场次 + 台词 + 动作）。

## 输入
L4 该集行（含本集爽点 + 结尾钩型 + 标记）+ L1 世界观 + L2 相关人物卡 + 前情（续集）

## 加载方法论
出稿前读 `references/craft/rhythm-curve.md` + `references/craft/hook-design.md` + `references/craft/dialogue-action.md` + `references/craft/dialogue-naturalism.md`（**首集**另读 `references/craft/opening-rules.md`）：

**结构（rhythm + hook）：**
- 单集按**微型三幕**写：前30s 钩子段（承上集悬念→抛本集张力）→ 中段 1-1.5min 冲突升级段（场次层层递进、无信息真空）→ 末30s 爽点释放 + 结尾钩
- **本集要么压要么放**（情绪弹簧·无中间态）：明确本集是「压」集还是「放」集，给本集情绪峰值打 1-10 强度，对齐 L4 钦定的爽点/钩型
- **结尾钩**按 L4 钦定的钩型落地（切断在最关键一刻；下一集开头能自然承接）
- **本集爽点**按 L4 钦定类型释放（先压抑蓄力再释放，配旁观者反应）
- **首集**前5秒必有冲击/悬念，套 opening-rules 的 6 开场模板之一；禁旁白铺垫/空镜/流水账

**台词与动作（dialogue-action）——落到每一句怎么写：**
- **信息前置**：第一句直接抛身份/冲突/目标，删光寒暄（你好吗/好久不见）；一句能说完绝不两句
- **潜台词动作化**：内心戏翻译成可拍的动作/身体反应，不裸写"他很愤怒"、不用旁白交代情绪
- **动作可视化**：正文用动词链+短句下指令（非"凶狠地""非常生气"），按本项目画幅预设镜头（9:16 竖屏＝特写/快剪/单主体；16:9 横屏＝中景/双人同框可用，动作仍具体到人）；情绪峰值给一个"夸张可拍"的外部动作（耳光/下跪/泼水）做记忆点
- **台词调性**按本剧题材取 dialogue-action 横表行，别串腔；台词精准到字（下游 S6 直接 lipsync）

**去 AI 味（dialogue-naturalism）——dialogue-action 管功能，这篇管真实感，配对各过一遍：**
- **七宗罪 linter**：每句扫 ON_NOSE_THEME（贴脸点主题）/ SELF_NARRATE_INTENT（独白念计划）/ STATE_EVAL（当面下评语「你很有天赋」）/ EXPO_DUMP（信息倾倒像招募启事）/ AWKWARD_REGISTER（书面腔·翻译腔·对偶格言·「～」代演技）/ VOICE_SAMENESS（谁说都一样）/ NO_SUBTEXT（有问必答零潜台词）/ ON_NOSE_EMOTION（口播已演过的情绪）——命中即改
- **对观众直给，对角色走潜台词**：开场钩子/反转/爽点/动作指令直给（观众秒懂）；关系/内心/对峙/暧昧走潜台词（说破即廉价）。「信息前置 ≠ 直白陈述」，最高效的台词常是最斜的
- **对调测试**：遮住人名读对白认不出谁 = VOICE_SAMENESS；若本剧已有声音圣经（`剧本/{项目名}/项目档案/台词圣经.md`），逐角色核「声音指纹 + 绝不会说的话」+ canon 台词红线（如不可喊名 / 只短冷否认）
- 情绪顶点留半句噎住/沉默/打断；抽象情绪词换能拍的具体物或动作；双人戏先给 A/B 各写一行「这场各要什么」（各怀目的）

- 写完对照 rhythm / hook / dialogue-action / **dialogue-naturalism** 尾部「自检表」逐条自查

## 输出落盘
`剧本/{项目名}/剧集/E<NNN>/E<NNN>_剧本_v1.md`

## 输出 schema（专业短剧剧本格式 · frontmatter + 正文 + 制作附注）
出稿前读 `references/剧本格式规范.md`（用户指定·行业通行格式），正文**严格照它落字**。要点：
- frontmatter：沿用已验证字段（`project / episode / title / aspect_ratio / scene_count / duration_estimate / based_on / status` + 各 revision 记录）；**`aspect_ratio` 必填**，须等于立项拍板的画幅
- **正文 = 专业剧本格式**（⚠️不是分镜脚本）：
  - 场次：`X-X`（集-场，如 `2-1`）；首场可冠 `第X集　X-X`；换场/时间跳跃/闪回空行重标
  - 时间地点行：`内/外　地点　时间`（日/夜/晨/傍晚）
  - 人物行：`人物：A、B、C`（全名、按重要性排）
  - 动作行：`△ ` 开头，散文现在时、可拍动词链（套 `references/craft/dialogue-action.md` 动作可视化）
  - 台词：`角色（提示）：台词`（角色对应 CHAR_）；内心独白 `角色(OS)：`、画外/未出场 `角色VO：`（= 非 lipsync）
  - 字幕/空镜：`【字幕：…】`、`【空镜：…】`；闪回 `闪回 … 闪回结束`
  - ⚠️**不写 #镜号 / 机位 / 运镜 / 逐镜景别**——下游 S2 故事板 / S4 分镜表的活（E002 v1–v3 踩此坑、v4/v5 修正）
  - 整体遵循**单集微型三幕**、**结尾必有钩子**（首集另需强开场）
- **制作附注**（正文后、以 `# 制作附注` 分隔）：场次↔SCENE_/光调/时长 锚点表、配音 budget、分镜预留（招牌镜+shot 量，留 S2/S4）、节奏自检、承接埋线、服装连续性——pipeline/QA 锚点全归这里，**不混进剧本正文**
