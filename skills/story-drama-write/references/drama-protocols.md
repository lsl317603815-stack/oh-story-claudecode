# 采访协议（按模式）

每种模式给：依据文件、根的候选（开场第一题）、采访项清单（根定之后由功能拆解推出，不是固定模板）、本模式特有的追问点。通用的密点追问在文末。

路径约定：`{项目名}/` 指 `剧本/{项目名}/`。依据文件**存在才读**，缺失不阻塞采访——候选来源降级并如实告知。采访纪律（不确认不落盘 / 一次一题 / 带候选 / 先问根 / 整段输入拆解入账 / 冲突当场亮 / 提案先行 / 粒度不越层）见 SKILL.md，本文件只给分模式的题面。

## 立项（世界观 + 项目大纲）

对应岗位说明书 `layers/L1_世界观.md`、`layers/L3_大纲.md`。产物：`{项目名}/项目档案/世界观.md`、`{项目名}/项目档案/项目大纲.md`。

### 依据文件
- 用户给的题材关键词、基调、立意；改编项目另加原著/小说速览（**改编走 `craft/adaptation-sourcing.md` 的回采纪律**）
- `craft/genre-guide.md`（13 题材定义与叠加公式，出题材候选用）
- `craft/rhythm-curve.md` + `craft/satisfaction-matrix.md`（全剧波形与爽点分布，出大纲候选用）
- 已有的同项目草稿（草稿只是候选，不是定稿）

### 画幅（**必答项·不许委托默认**）
立项采访**必须**有独立一题问画幅，两个候选二选一，不许用「先按常规」糊过去：
- `9:16` 竖屏（推荐给短剧投流）——单集 1–2 分钟、上半身特写/快剪/单主体，群像装不下；建置要压缩（见 `craft/rhythm-curve.md`「竖屏建置压缩术」）
- `16:9` 横屏——中景与双人同框成立、环境信息可进画面，容得下群像调度与更长的场

后果写清：画幅决定每一场怎么写，中途改要重过立项采访并回改已写的集。拍板后写进 `{项目名}/项目档案/世界观.md` 的 `画幅` 字段，此后每集剧本 frontmatter 的 `aspect_ratio` 都必须等于它。

### 根的候选（第一题）
- 核心幻想是什么（观众来看什么爽）
- 主角为什么是他（身份差 / 信息差 / 能力差）
- 世界的主货币与规则边界是什么
- 关系引擎是什么（谁跟谁的拉扯撑起全剧）
- 按原著/草稿顺序过（改编项目、作者对源大体满意时）

### 采访项（根定后从功能拆解推出；下表是常见项，不是模板）
| 采访项 | 密/疏 | 问什么 |
|---|---|---|
| 画幅 | 密 | 竖屏还是横屏（见上，必答） |
| 题材定位 | 密 | 主题材＋副题材（≤3 种）；核心受众、典型爽点、关键要素 |
| 基调与风格 anchor | 密 | 喊得出作品名的调子；下游出图/分镜直接引用 |
| 核心规则 | 密 | 世界怎么运转；哪条规则是爽点的来源 |
| 主线 logline | 密 | 一句话说完全剧；说不完就是还没想清 |
| 全剧波形 | 密 | 起势/攀升/风暴/决战各占多少集、强度怎么递增 |
| 爽点分布 | 密 | 5 分型（身份碾压/打脸复仇/逆袭翻盘/情感爆发/悬念揭秘）主副辅配比 |
| 集数口径 | 密 | 固定集数（配三幕结构）还是滚动无上限 |
| 单集时长 | 密 | 决定信息密度：1 分钟严格单线，1.5–2 分钟可双线各走半步 |
| 反派梯队 | 疏 | 小/中/大/隐藏各是谁（细节留角色模式） |
| 命名与语汇 | 疏 | 专名、称谓；改编项目先查原著再用 |
| 禁碰项 | 疏 | 正文不许怎么写；每条单独问 |

### 本模式追问点
- 「这个爽点，观众在第几集第一次拿到？」——前 3 集不给爽的短剧没有第 4 集
- 「这条规则观众怎么知道？靠谁的嘴说出来？」——竖屏没有旁白位
- 「主题材和副题材冲突吗？」（genre-guide 的避开组合）
- 「滚动还是固定？」——选滚动就不许再问「结局怎么收」，那是到时候的事

## 角色

对应 `layers/L2_人物.md`。产物：`{项目名}/角色总库/CHAR_{名}.md` ＋ `{项目名}/角色总库/人物索引.md`。

### 依据文件
- 已定稿的 `{项目名}/项目档案/世界观.md`（角色不得与之冲突）
- 改编项目的原著人设（保留项来源，人名/专名先查原著再用）
- `craft/villain-design.md`（角色定位含「反」时必读）
- `craft/dialogue-naturalism.md` 的声音卡四引擎（自称/双声道/演变弧/男女差）

### 根的候选（第一题）
- 这个角色的**功能位**（主角/对手/盟友/催化剂/见证者/靠山）
- 他与主角的第一次交锋
- 他挡住主角的哪个欲望

### 采访项
| 采访项 | 密/疏 | 问什么 |
|---|---|---|
| 功能位与重要度 | 密 | 他在剧里干什么；删了谁接手 |
| 核心动机 | 密 | 他要什么；不给会怎样 |
| 反派三问 | 密 | （定位含反）动机／支撑／节制——为何不更早下手 |
| 反派层级 | 密 | 小/中/大/隐藏；隐藏反派必须埋 ≥3 处伏笔锚点 |
| 外形 | 密 | 发型/脸型/体型/标志性服装/年龄——这段直接喂图像模型，要写实可画 |
| 声音指纹 | 密 | 自称、口头习惯、**绝不会说的话**；遮住人名认得出他 |
| 关系 | 密 | 与已有角色逐个过一遍 |
| 出场集 | 疏 | 第几集进场、第几集退场 |

### 本模式追问点
- 「遮住名字读他的三句台词，认得出是他吗？」——认不出就是 VOICE_SAMENESS
- 「他不知道后面的剧情，还会这么做吗？」
- 「这张卡的外形段，画师能照着画出来吗？」

## 分集纲

对应 `layers/L4_分集.md`。产物：固定集数→`{项目名}/项目档案/分集表.md`；滚动无上限→`{项目名}/项目档案/集纲.md`（已锁集事实摘要＋2–4 集软前瞻）。

**提案先行**：不要空手问「第 7 集写什么」。先按已定的波形和爽点分布摆出整段提案（每集一行：梗概＋本集爽点＋结尾钩型），再只对真正开着的决定出题。

### 依据文件
- `{项目名}/项目档案/项目大纲.md`（波形与爽点分布，分集必须对齐它）
- `{项目名}/角色总库/人物索引.md`（角色 ID 必须 ∈ 索引）
- `craft/hook-design.md`（5 钩型）＋ `craft/satisfaction-matrix.md`（5 爽点分型）
- 已锁剧本（滚动项目：已锁事实不许在纲里重构）

### 根的候选（第一题）
- 从哪一段排（本段起止集号）
- 这一段要兑现哪个爽点
- 这一段结束时观众该知道什么、还欠着什么

### 采访项
| 采访项 | 密/疏 | 问什么 |
|---|---|---|
| 分段范围 | 密 | 这次排哪几集；剩下的标「待排」 |
| 逐集梗概 | 密 | 一句话一集，谁做什么 |
| 本集爽点 | 密 | 5 分型取一＋强度★；强度随波形递增 |
| 结尾钩型 | 密 | 悬念/反转/情绪/信息/危机取一；**连续 3 集不重复** |
| 出场角色 | 密 | 角色 ID 逐集列，须 ∈ 人物索引 |
| 关键集标记 | 疏 | 哪几集是🔥（重大转折/高潮/揭秘） |
| 卡点集 | 疏 | 免费段停在第几集（竖屏小程序剧的商业锚） |

### 本模式追问点
- 「这一集的爽点，观众能不能一眼看出来兑现了？」——爽点必须可证伪（落进球/比分，不是台词说「好厉害」）
- 「钩型跟前两集重了吗？」
- 「这一集压还是放？」——情绪弹簧无中间态
- 「这条债哪一集还？」——爽当集给，债跨集欠，但每笔债要有还期

### 硬门（终审前跑，不合格回采访补项，不自行凑）
- 爽点强度沿波形递增，全剧最强落决战段；同类型爽点不连续
- 钩型连续 3 集不重复
- 每集角色 ID 全部 ∈ 人物索引
- 滚动项目：软前瞻 2–4 集，不被假定结局约束

## 单集构思案（写全稿前的最后一道门）

产物：`{项目名}/剧集/E{NNN}/E{NNN}_剧情构思案.md`。**构思案锁版前一个字全稿都不许写。**

### 依据文件
- 本集在分集纲里的那一行（爽点＋钩型＋梗概）
- 最近一集已锁剧本（承接口）＋ `{项目名}/项目档案/前情提要.md`
- 出场角色的 CHAR 卡与声音卡
- 改编项目：原著对应段落（按 `craft/adaptation-sourcing.md` 事件锚点检索，不用概念词检索）

### 根的候选（第一题）
- 本集的货币是什么（糖/爽/虐/悬，一集一货币）
- 本集要清哪笔旧账
- 本集从哪个画面开场

### 采访项
| 采访项 | 密/疏 | 问什么 |
|---|---|---|
| 剧情承接 | 密 | 上承什么尾态、时间线隔多久 |
| 本集功能 | 密 | 2–4 条，删了哪条这集就没用了 |
| 主憋点 | 密 | 压什么、压多久 |
| 爽点与清账口 | 密 | 当众可拍的释放长什么样 |
| 结尾钩 | 密 | 切在哪一刻；下一集怎么接得上 |
| 分场 beat | 密 | 每场：谁/哪里/发生什么/场次功能 |
| 代价延账 | 疏 | 本集新造的代价各落哪一集 |

### 本模式追问点
- 「他不知道后面剧情，还会这么做吗？」（逐人物过 beat）
- 「称谓和寒暄对得上他俩实际相识多久吗？」——面试才隔一天不能说「好久不见」
- **发明机制检**：这案子里的规则/数值/道具功能，指得出世界观文件哪一句吗？指不出就撤掉回设定找正解。「是既有口径的某某形态」这种归类句**不是出处**，正是替它找理由的典型句式。

## 密点追问（通用）

追问 2–4 轮，问到下面这些有答案即停；作者说「就这样」立即停：
- 谁在场 / 什么触发 / 配角什么反应
- 观众在第几集从哪个**可见载体**得到它（登记不等于兑现）
- 与已拍板项、与禁碰项的边界在哪
- 这条改了，哪几集要回改
