# 中文正文文风卫生门

本门只处理确定性的排版式表达污染：表情符号、颜文字、火星文、重复装饰标点和不可见字符。它不判断文学质量，不替代语言门、去 AI 味、人物声线或题材文风。

## 默认策略

未配置 `设定/文风.md` 时使用 `publish-clean`：

- 表情符号：blocking；
- 颜文字：blocking；
- 火星文：blocking；
- 三个及以上问号/感叹号/点号、两个及以上波浪号等装饰标点：blocking；
- 有功能的单个问号/感叹号、`？！`、规范省略号 `……` 和破折号不由本门处理，继续交给本书文风与标点 Gate；
- Markdown 代码、网址和邮箱等明确非叙事结构机械保护；
- 用户确需逐字保留时，在正文上层目录放置 `.style-hygiene-whitelist`，每行登记一个完整字面量。白名单不自动外扩，不豁免语言门。

## 本书选项

用户明确讨论行文风格时，可把下面一节写入本书 `设定/文风.md`。卫生配置与文风笔调相互独立：只有这一小节时，不应把它误判成完整自定义文风。

```markdown
## 文风卫生

- 文风卫生：出版级纯中文
- 表情符号：禁止
- 颜文字：禁止
- 火星文：禁止
- 重复标点：禁止
```

可选值：

| 选项 | 含义 |
|---|---|
| `禁止` | 命中即 blocking，修改后复扫 |
| `对白内允许` / `引用内允许` | 引号内放行，引号外仍 blocking；适合聊天记录或特定角色声线 |
| `复核` / `提示` | advisory，必须通读语境决定 |
| `允许` | 本类不报告；只在作者明确选择时使用 |

整组选项也可用：

- `文风卫生：出版级纯中文`：四类全部禁止；
- `文风卫生：对白弹性`：表情、颜文字和火星文只允许在引号内，重复标点仍禁止；
- `文风卫生：宽松复核`：四类只作 advisory。

具体选项行优先于整组预设。

## 执行顺序

中文正文先过 `language_gate.js`，再运行：

```bash
node scripts/check-style-hygiene.js --check --fail-on=blocking <正文文件...>
```

通过后再进入错别字、AI 句式、退化、文风画像和语义审查。blocking 只修改命中单元并复扫；不得用删除整段正文、改剧情或扩大白名单来求过门。

## 火星文边界

火星文词表只收高置信的陈旧聊天体组合，不用单个生僻汉字判定，以免误伤人名、方言、古文或题材专名。项目确需年代聊天语感时用“对白内允许”或精确白名单，不要关闭其他类别。
