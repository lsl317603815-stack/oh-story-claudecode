# 起点中文网 Quality Rubric

## 评分标准

| 指标 | PASS 标准 | FAIL 标准 |
|------|----------|----------|
| 爽点密度 | 情绪节点（升级/打脸/获宝）间隔与本书节奏相符（参考：约每 3000 字一次） | 长段落没有情绪节点，读者等不到兑现 |
| 升级节奏 | 实力突破的间隔与本书成长线一致 | 长期没有任何成长或突破 |
| 金手指使用 | 金手指在推进中起作用，出场有理由 | 长期搁置到读者忘了它，或每章硬提一句 |
| 日更支持 | 大纲支持 4000 字/天节奏（每章 2000 字，每天 2 章） | 无日更计划，章节长度不规律 |
| 追读余势 | 每章结尾有悬念/决定/行动/关系变化/阶段目标之一，强度按章节定位 | 连续 3 章无下一步推动力或情绪断裂 |
| 角色存在感 | 主角每章出场并推进 | 连续多章主角不出场或无推进 |
| 追读期待 | 章尾钩子与情绪连续性支撑后续期待 | 连续 3 章无钩子或情绪断裂；追读比须用实际数据验证，不凭文本预估 |

## 使用方式

- story-review 的 story-architect 视角引用此标准
- advisory only，不 blocking
- 用户可自定义阈值
