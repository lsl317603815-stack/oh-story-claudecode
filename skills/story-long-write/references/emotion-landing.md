# 情绪落地手册

> 配套闸口：`scripts/check-emotion-floor.js`。本文件回答「该写成什么」，闸口只回答「够不够」。

## 为什么需要这份文件

情绪没有固定译法：上下文已经让读者感觉到的，不用再补；需要落地时，优先落在选择、台词、物件和后果上，身体细节要有后果才留，最准确的时候直写一句也可以（见 `writing-craft.md` 第 1 节）。但全部质检脚本都是禁止型的：查 AI 味、查套路、查电报体，没有一条下限。

于是出现一个漏洞：**干脆不写情绪也能通过所有检查**。结果就是正文没有体温，读者判为平淡——事件在推进，但感觉不到人物在承受什么。

**删除不是克制。** 删掉「她很愤怒」而不让情绪在任何地方落地，是把情绪弄丢了，不是把它写好了。

**闸口的口径。** `check-emotion-floor.js` 只数下面三类能机械识别的落点；直写、选择、台词、后果同样成立，但它数不到。所以硬拦截只在接近零体温时触发，低于建议线只是提醒；被拦时补一个有功能的落点，不要为了过线堆身体词。

## 三通道

闸口计数的是下面三个通道；同一章里落点只挤在一个通道，人物容易像在旁观自己。

| 通道 | 是什么 | 例 |
|---|---|---|
| **somatic** 身体信号 | 身体自己发生、不受意志控制 | 心跳、喉咙、指尖、冷汗、呼吸、耳鸣、牙关 |
| **impulse** 失控动作 | 做了本来不打算做的事 | 攥紧、摔、僵住、退了半步、手一滑、话说到一半停下 |
| **sense** 具身感官 | 贴着身体的感觉，不是环境描写 | 发烫、发凉、发麻、刺痛、酸胀、发堵 |

**impulse 是最被低估的一个通道。** 只写身体感觉，读者知道人物难受；写出失控动作，读者才知道人物**撑不住了**。主角每一步都在计划内、每句话都答得漂亮，是平淡最常见的成因——赢得太顺等于没有赌注。

## 落点参考表

这是身体与动作一路的参考，不是必须的译法：选择、台词、后果能落地时优先用它们。不要照抄词条，看的是「这个情绪在这个强度下，人会先做什么」。

| 情绪 | 低强度（压得住） | 中强度（露痕迹） | 高强度（失控） |
|---|---|---|---|
| **愤怒** | 呼吸变慢，说话前多停一拍 | 攥紧手里的东西，指节发白，语速变快 | 摔东西，打断对方，说出后悔的话 |
| **恐惧** | 手心出汗，反复确认同一件事 | 后背发凉，站起来又坐下 | 腿软，抓住旁边的人或物，说不出完整句子 |
| **羞耻** | 眼神躲开，话题岔走 | 耳朵发烫，声音变小 | 起身离开，或反过来攻击对方 |
| **心碎** | 动作变慢，做熟悉的事出错 | 喉咙发紧，吞咽困难，看向别处 | 蹲下，手撑住膝盖，长时间说不出话 |
| **隐忍** | 把手放到桌下 | 牙关发紧，笑一下再开口 | 指甲掐进掌心，声音抖了一下又稳住 |
| **狂喜** | 反复看同一样东西 | 手抖到拿不稳，笑出声后立刻收住 | 抱住人，或原地站着说不出话 |
| **绝望** | 停止争辩，开始整理东西 | 眼睛干涩发疼，动作机械 | 松手，任东西掉在地上 |

**用法**：先定情绪和强度，取一到两个落点，**放在本章压力最高的地方**，不要全章均匀撒。密度低不是因为没写够，是因为该重的地方没重。

## 反模式

**一、精致戏剧反应复读。** 「头皮发紧」「眼皮一跳」「心口一沉」「胃里翻涌」这四个连用会让情绪贬值。能写普通动作、普通感觉就写普通动作、普通感觉：眼睛又酸又胀比头皮发紧更可信。闸口对同一词组出现 ≥4 次判 blocking，就是防止本手册被用成刷分表。

**二、把情绪写成解释。** 「她意识到自己其实一直在害怕」是叙述者在替读者总结，不是让读者感觉到。改成她做了什么选择、说了什么、带来什么后果；确实最准时，直写一句「她怕了」也比绕一圈解释好。

**三、只在章尾补体温。** 前 2000 字零落点、最后两段集中补，读者已经在中间流失了。落点要跟着压力走，压力在哪落点在哪。

**四、程序流场景不给落点。** 谈判、文书、信息交接这类场景最容易写成零体温——所有内容都是「谁说了什么、文件写了什么」。这类场景恰恰最需要落点：对方停顿的那一拍、自己签字时笔尖顿住、拿到东西后手心的汗。

## 与闸口的对应

| 闸口 finding | 说明 | 处理 |
|---|---|---|
| `somatic-floor-critical` | 密度低于硬下限，接近零体温 | 回到压力最高的 2-3 个节点补落点 |
| `somatic-floor-low` | 低于建议下限 | 挑一到两个场景补，不要全章撒 |
| `emotionless-run` / `-critical` | 连续多少字无可计数落点 | 情绪已靠台词、选择或后果交代清楚的可不动（advisory）；硬上限时在转折处补一个落点 |
| `channel-narrow` | 落点挤在单一通道 | 补 impulse：一个「做了本来不打算做的事」 |
| `single-channel-spam` | 刷密度或复读精致反应 | 换落法，不是加数量 |
| `no-loss-of-control` | 高压章全程无失控动作 | 给主角一个非计划反应 |

## 何时放宽

低压章、信息整理章、关系回收章可以用 `--pressure=low`，阈值下调但下限不取消。**没有任何章节可以零落点**——过场章也有人在场，人在场就有体温。

高压章（对峙、摊牌、生死、揭穿、付费点前后）用 `--pressure=high`，此时失控点是硬要求。
