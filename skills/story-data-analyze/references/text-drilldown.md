## 1. 诊断原则

指标定位的是读者的“决策窗口”，不是自动判定某一句有罪。

```text
读者来源与预期
→ 看到包装/文本
→ 理解人物、目标、冲突和收益
→ 判断已投入是否值得
→ 判断继续投入能得到什么
→ 点击下一章 / 收藏 / 追更 / 回访 / 触底
→ 后台指标
```

执行规则：

1. **跨边界读取**：N→N+1 异常至少读第 N 章全文、章末 10%–20%、N+1 标题和开头 200–500 字；必要时上溯 N-1/N-2 的期待债。
2. **区分单点与结构性衰减**：单点断崖检查跨章决策窗口；连续多章缓降检查完整剧情单元、兑现周期和卖点疲劳。
3. **无字数级数据时不伪造具体掉点**：先得到候选范围，再靠文本证据筛选；不能说“读者就在第 7 段离开”。
4. **包装会改变进入者结构**：书名、封面、简介或标签变更后，后续留存变化可能来自读者换血。
5. **先做最小可证伪修改**：优先修承诺错配、信息顺序、重复、兑现和承接；只有多点证据一致才重排单元或重写多章。
6. **不靠虚假悬崖骗指标**：加一句机械卡点可能把流失推迟一章，并损害追更、评论和长期信任。

## 2. 标准文本证据卡

每个重点异常必须填：

```markdown
### 异常节点：[指标 / N→N+1 / 30→60秒]

- 官方定义与分母：
- 数据现象：[绝对人数 + 比率 + 对照窗口]
- 读者在此节点做的选择：
- 决策前文本范围：
- 决策后入口范围：
- 上游承诺：书名/简介/导语/前章提出了什么
- 原文证据：文件、章节、段落或行号
- 首要机制假设：
- 备选解释：渠道、版本、更新、样本等
- 最小修改：
- 主指标：
- 护栏指标：
- 归因置信度：低 / 中 / 高
```

把因果链写完整：

```text
文本中可观察的问题
→ 造成认知/情绪/期待上的什么阻力
→ 读者为何在该节点停止
→ 修改改变哪个中间机制
→ 哪个指标应先变化
→ 哪些护栏不得恶化
```

禁止只写“钩子不强，所以加强钩子”。

## 3. 长篇：分发与包装

### 3.1 只有渠道阅读下降

先查：签约/推荐阶段、更新连续性、违规通知、发布时间、分类标签、渠道结构。没有展示量时，不从渠道阅读人数推断 CTR，也不先改正文。

可读文本仅用于检查包装一致性：

- 书名、封面、简介；
- 分类、标签、关键词；
- 第一章开头 200–500 字；
- 包装承诺的核心梗首次出现位置。

### 3.2 有展示→阅读转化且偏低

**首查位置**

- 书名是否在缩略场景下清楚表达题材、人物关系与核心反差；
- 封面是否能识别题材和书名；
- 简介前 1–3 句是否给出主角处境、冲突和差异化收益；
- 简介承诺是否在正文首屏兑现；
- 标签是否吸引了错误读者。

**修改方向**

- 让书名/简介表达同一个核心卖点；
- 删除正文无法持续兑现的点击诱饵；
- 把对应事件、异常或人物关系前移到第一章首屏；
- 一次只测试一个包装主变量，优先使用平台原生多书名/封面实验。

**因果链**

```text
题材和阅读收益更易识别
→ 正确读者更愿意进入
→ 展示→阅读提高
→ 包装与首章一致
→ 1→2不被错误读者和标题党反噬
```

**护栏**：首章承接、1→2、负面评论中的“货不对板”、后续渠道结构。

## 4. 长篇：黄金前三章

黄金前三章必须计算 `A1/A2/A3/A4`，分别把异常映射到完整责任窗口。

### 4.1 第 1 章→第 2 章偏低

**必读范围**

1. 书名和简介；
2. 第 1 章前 200–500 字；
3. 第 1 章全文；
4. 第 1 章末 10%–20%；
5. 第 2 章标题和开头 200–500 字；
6. 第一章细纲及其承诺的“小兑现”。

**逐段检查**

| 位置 | 查什么 | 常见问题 | 修改动作 |
|---|---|---|---|
| 前 200–500 字 | 谁、当前处境、正在发生什么、题材梗是否落地 | 天气/背景热身；人名设定过载；书名梗迟到 | 从具体事件、异常动作或冲突台词切入；设定随行动释放 |
| 中段 | 主角是否选择、行动，信息是否持续增加 | 反复解释/受辱；主角只被推着走；同义反应重复 | 合并重复；前移主角选择、代价和结果 |
| 章内兑现 | 本章是否至少改变一项状态 | 只制造危机不支付任何收益；核心机制仍是说明 | 增加小兑现、可见状态变化或机制第一次回应 |
| 章末 | 下一步是否具体且重要 | 抽象感叹、机械黑影/短信；悬念不影响主线 | 把钩子改成具体行动、选择、期限或代价 |
| 第2章入口 | 是否立即承接第1章 | 切视角、回忆、解释成误会；标题提前泄底 | 直接履行上章未决动作，背景后置；调整剧透标题 |

**核心问题**

- 第 1 章内是否建立主角、核心困境、差异化机制和继续阅读价值？
- 是否只有痛苦，没有希望、能力或关系支点？
- 是否只有刺激，没有人物认同和行为逻辑？
- 读者是否收到第一笔小收益，并清楚第 2 章会得到什么？

**目标因果链**

```text
首章更快建立人物认同和题材承诺
→ 理解成本下降
→ 获得首笔收益/状态变化
→ 下一步具体且可信
→ 进入第2章的预期收益提高
→ 1→2改善
```

**护栏**：2→3、人物逻辑、世界规则、后续伏笔、“节奏太快/看不懂”反馈。

### 4.2 第 2 章→第 3 章偏低

**必读范围**

- 第 1–3 章完整文本；
- 第 2 章末 10%–20%；
- 第 3 章标题和开头 200–500 字；
- 黄金三章的首个小高潮/核心机制验证点。

**重点检查**

- 第 2 章是否放大核心梗，还是重复第 1 章解释；
- 第一章建立的目标是否推进；
- 主角能力、关系、资源或困境是否第二次发生可见变化；
- 是否变成纯过渡、纯训练、纯说明；
- 第一章提出的期待是否开始“付利息”；
- 第 3 章是否通向首次有效应用或小高潮，而非开启无关支线。

**优先修改**

- 合并重复铺垫；
- 把核心机制的首次有效应用前移；
- 给第 2 章增加结果、代价或关系变化；
- 让第 3 章立即承接兑现，而不是重新冷启动。

**目标因果链**

```text
第2章不再重复承诺，而是让核心梗实际运转
→ 读者看到投入会持续产生新变化
→ 对黄金三章的收益预期上升
→ 2→3改善
```

**护栏**：3→4、前 5 章累计到达、核心机制规则、人设一致性、爽点前移后的后续期待真空。

### 4.3 第 3 章→第 4 章偏低

**必读范围**

- 第 1–4 章；
- 第 3 章全文和章末；
- 第 4 章标题与开头；
- 黄金三章结束后的第一个剧情单元目标。

**重点检查**

- 黄金三章是否只结束了一个小事件，却没有开启长期目标；
- 核心机制是否已出现但看不出可重复升级空间；
- 主角、对手、代价和下一阶段目标是否明确；
- 第 4 章是否像“另一本书”的开头，切地图、切人物或转为说明；
- 前三章高刺激后是否突然降档进入善后。

**优先修改**

- 在第 3 章兑现小目标的同时开启更大的具体问题；
- 展示核心机制可持续扩展的下一层收益/代价；
- 压缩第 4 章冷启动和复述，直接承接前章状态变化；
- 若前三章方向不统一，重排单元目标而非只补章末一句。

**护栏**：第4→5、前7章累计到达、长期目标可信度、不过度提前泄露后续底牌。

## 5. 长篇：任意章节与剧情单元

### 5.1 单点 N→N+1 异常

**最小读取范围**

- 第 N-1 章末；
- 第 N 章全文；
- 第 N 章末 10%–20%；
- 第 N+1 章标题及开头 200–500 字；
- 当前剧情单元细纲。

**六项检查**

1. **全章价值**：是否推进主线、关系、资源、信息、目标中的至少一项；是否大量重复已知内容。
2. **期待兑现**：本章承诺的收益是否到账；是否“只拉仇恨不释放、只解释不改变、铺垫很大兑现很小”。
3. **状态变化**：主角是否做选择；目标、风险、关系、资源、身份或情绪立场是否变化。
4. **章尾余势**：下一步是否具体、重要、可行动；是否反复使用同一种机械悬崖。
5. **跨章诚信**：N+1 是否立即履约；是否切走、回忆、复述、把危机解释成误会或标题泄底。
6. **单元位置**：蓄力是否过长，高潮后是否出现期待真空，旧目标关闭前是否建立新目标。

**修改动作**

- 删除/合并重复信息与反应；
- 前移有效状态变化；
- 补足被拖欠的小兑现；
- 把抽象目标改为具体行动、期限或代价；
- 修复 N 与 N+1 的真实承接；
- 调整标题，避免剧透或“纯铺垫感”；
- 不用掐断完整场景和角色自然知道的信息制造假钩子。

**护栏**：N+1→N+2、后续 3–5 章到达、回访/追更、评论中的“水/骗/强行断章/看不懂”、逻辑与人设。

### 5.2 多章均匀衰减或连续低点

**读取范围**

- 异常区间前后各 2 章；
- 完整剧情单元或桥段；
- 卷纲、单元目标和期待债；
- 最近同类爽点/冲突出现记录。

**检查问题**

- 核心卖点是否偏移；
- 同一受辱、冲突或解释是否重复；
- 长期目标是否模糊；
- 延迟满足是否没有阶段利息；
- 高潮后是否出现期待真空；
- 换地图是否清空旧关系和读者投入；
- 支线是否多章不推进主线；
- 章节长度、更新时间或读者渠道是否同步变化。

**修改动作**

- 压缩完整单元而非每章硬加悬崖；
- 提前阶段兑现；
- 恢复核心卖点；
- 合并重复冲突；
- 旧目标完成前铺设新目标；
- 删除或后移无主线收益的支线。

**护栏**：异常区间后 3–5 章到达、单元高潮满意度、追更、世界观/人设/伏笔连续性。

## 6. 长篇：书架、追更、催更与回访

### 6.1 加书架弱

它回答“是否值得以后再找回来”，不是单章顺不顺。

**读取范围**：书名简介、前 3 章、读者常见离开点、长期目标、核心关系、成长/机制循环。

**查什么**

- 核心梗能否支撑多轮变化，而非一次性噱头；
- 主角是否值得长期陪伴；
- 是否只有短期悬念，没有中长期收益；
- 当前事件结束后是否看不见下一阶段；
- 是否有自然的阶段兑现点让读者产生保存价值。

**修改**：明确长期目标和成长路线；在小兑现时展示更大的未完成价值；强化持续性机制和关系投入；让简介表达长期阅读收益。不要用作者口播求收藏代替内容价值。

**护栏**：1→2、2→3、回访、追更、长期目标是否透支。

### 6.2 追更弱

追更人数是阅读最近 7 日更新章节的有效读者数，先分开内容与更新稳定性。

**读取范围**：最近 7 日发布章、最新 1–3 章、当前单元结尾、下一阶段目标、更新轴。

**查什么**：最新单元是否有实质进展；是否过度圆满；是否卡在无意义动作；读者是否相信下一更有新内容；连续假钩子是否透支信任。

**修改**：补阶段收益；明确下一目标/对手/期限/关系变化；修复撤回式承接。更新频率问题单独处理，不用正文背锅。

**护栏**：下一更回访、最新评论、下一章承接、“注水/骗追更”反馈。

### 6.3 催更弱

先确认到达最新章的合格人数和更新间隔；催更为 0 在无人追平时没有文本诊断意义。

**读取范围**：最新章全文和最后 20%、最近 2–3 章蓄力/兑现、更新时间轴。

**查什么**：最新章是否停在高价值未完成状态；读者是否关心结果；卡点前是否有足够投入；是否刚完成高潮而自然需要喘息；是否更新太勤而没有催更窗口。

**修改**：提高待解决问题的具体性和重要性；补足人物投入、代价或收益；用决定、行动和关系变化制造余势，不掐断完整场景骗催更。

**护栏**：下一章兑现、追更、差评、钩子诚信。

### 6.4 回访/继续阅读弱

**读取范围**：常见会话结束位置前后 1–3 章、返回时首先看到的标题/开头、长中短三层期待、更新记录。

**查什么**：是否留下值得记住的目标；是否形成角色投入或稳定阅读收益；上次会话是否结束得过于圆满；返回入口是否先复述/转场；是否由断更、推送、渠道造成。

**修改**：强化跨会话可记忆的目标/关系/待兑现收益；高潮后建立新方向；精简返回入口的冷启动；修复更新稳定性。

**护栏**：返回后的阅读深度、追更/书架、单次阅读时长、新读者是否被过量前情复述拖慢。

## 7. 短故事：展示到触底

平台给出的字数映射是近似范围，不代表读者精确停在某个字：

| 节点 | 官方近似文本范围 | 实际读取范围 |
|---|---|---|
| 阅读→15秒 | 前约 300 字 | 标题/导语 + 前 300–500 字，覆盖第一个自然场景 |
| 15→30秒 | 约 500–1000 字 | 前 1000 字，并重点看 250–1100 字的承接 |
| 30→60秒 | 约 1000–2000 字 | 前 2000 字，并覆盖首个小兑现/反转 |
| 60秒→触底 | 2000 字后至结尾 | 全篇结构，重点找第一个后续掉点及 60%–100% |

### 7.1 展示→阅读偏低

**首查**：标题、封面、导语、标签、第一屏。

**问题**：题材/关系/冲突不易识别；标题只有猎奇没有故事；封面与文案吸错人；导语承诺正文迟迟不兑现。

**修改**：明确人物关系和核心异常；让标题、封面、导语表达同一收益；删除无法兑现的诱饵。

**护栏**：15 秒、30 秒、触底、评论“标题党”。点击升而 15 秒跌，说明包装优化失败或吸错人。

### 7.2 阅读→15秒偏低：前约 300 字

**问题检查**

- 是否以天气、履历、泛化感慨或背景说明开头；
- 是否立即知道谁、发生什么、为什么重要；
- 人名、关系和时间线是否过载；
- 第一处异常/背叛/危机/欲望/反差是否出现；
- 首句很炸但随后马上解释降温；
- 标题/导语承诺是否在首屏得到验证。

**修改**

- 从具体事件、异常动作或冲突台词切入；
- 前移人物关系、赌注和不可逆变化；
- 删除背景热身，背景随行动释放；
- 减少同屏人名和时间线；
- 让第一个钩子继续推进而非立即撤回。

**因果链**

```text
首屏理解成本下降，题材与冲突立即可见
→ 读者确认内容与包装一致
→ 退出冲动降低
→ 15秒留存改善
```

**护栏**：30/60 秒、理解度、主角认同、反转所需信息。

### 7.3 15→30秒偏低：约 300–1000 字

**问题**：首钩后掉入背景解释；冲突没有升级或新信息；主角没有反应/目标/选择；连续描写同一情绪；读者不知道为何关心。

**修改**：把背景嵌入行动；增加第一步决定；让冲突产生具体后果；把抽象情绪换成动作/关系变化；合并同义反应。

**护栏**：60 秒、动机理解、情绪建立、反转公平性。

### 7.4 30→60秒偏低：约 1000–2000 字

**问题**：事件仍停在原地；只有压迫没有反抗/希望/新信息；第一层期待没有支付利息；读者已能猜完全文；主角始终被动；证据与反应堆叠。

**修改**：在 2000 字前给第一次状态变化、小反击、小发现、小代价或关系转折；压缩重复；让主角做不可逆选择；开启下一层期待。

**护栏**：触底、高潮力度、反转合理性，避免太早释放导致后半段真空。

### 7.5 60秒→触底偏低：中后段

**读取范围**：2000 字后全篇、每个场景起止、关键反转、高潮前后、最后 20%。

**问题**

- 重复同一种受虐、争吵、解释或证据；
- 支线不服务主悬念；
- 视角/时间线切换成本高；
- 延迟满足无阶段收益；
- 反转过早可猜或靠故意藏信息；
- 情绪长期同档造成麻木；
- 高潮过晚、高潮后解释性收尾过长；
- 某场景删除后不影响因果，说明没有信息增量。

**修改**

- 合并重复桥段；
- 提前关键发现/反击/高潮触发；
- 删除不服务主线的支线；
- 用新变量升级，不只加重同一种伤害；
- 补小兑现后再蓄力；
- 调整信息顺序，让反转可回溯；
- 缩短高潮后的解释，但保留必要的人物反应和情绪回报。

**护栏**：有效阅读时长、高潮到达、评论/点赞/收藏、反转公平性、人物动机。机械缩短抬高触底而损害情绪回报，不算成功。

### 7.6 触底高但互动弱

**读取范围**：高潮与最后 20%–30%、最后一段/一句、全文承诺清单。

**问题**：只是篇幅短或快速滑到底；结局有答案没情绪；主角收益/对手代价/关系变化不可见；突然总结说教；反转只是意外而未重构前文。

**修改**：写实后果与人物反应；补足收益、代价和关系落点；用具体动作/画面/台词收束；删除泛化升华；保留可讨论余味但不制造逻辑漏洞。

**护栏**：触底、有效阅读时长、评论质量、负反馈。

## 8. 组合异常

| 组合 | 优先解释 | 首查位置 |
|---|---|---|
| 点击低、15秒高 | 包装识别弱，进入者认可内容 | 书名、封面、导语 |
| 点击高、15秒低 | 包装与正文错配/点击诱饵 | 包装 + 前300字 |
| 15秒低、后续条件留存高 | 首屏门槛高 | 前300字 |
| 15秒高、30秒低 | 钩子后掉入解释 | 300–1000字 |
| 30秒高、60秒低 | 第一单元无变化/无小兑现 | 1000–2000字 |
| 60秒高、触底低 | 中段重复、过长或期待真空 | 2000字后至高潮 |
| 触底高、互动低 | 快速触底或结尾无情绪余值 | 阅读时长 + 结尾 |
| 章间承接高、回访低 | 单次顺滑但缺长期价值 | 单元目标、长期期待、最新章 |
| 加书架高、回访低 | 有保存意愿但持续兑现/更新弱 | 更新轴 + 返回入口 |
| 跟读高、追更低 | 能顺手往下读但不愿长期承诺 | 最新单元、长期收益 |

## 9. 修改因果链与发布前审查

### 9.1 修改优先级

按成本和证据依次处理：

1. 修正数据口径与干扰事件；
2. 修正包装—正文承诺错配；
3. 调整信息顺序，让冲突、目标、卖点更早可理解；
4. 删除重复和无效解释；
5. 补足小兑现、状态变化和真实跨章承接；
6. 调整整章结构；
7. 只有连续多点证据一致时，重排剧情单元或重写开篇。

### 9.2 必须写出的反事实

每个修改方案回答：

```text
如果不改，这批读者为什么仍会在同一节点离开？
如果按方案改，读者在离开前会多看到什么新信息/行动/收益？
它为何足以改变“继续还是退出”的判断？
若指标没有改善，哪条机制假设被否证？
```

答不清时，不发布该修改。

### 9.3 发布前对抗审查

至少完成三条审查线：

1. **结构/读者体验**：修改是否真的发生在断点之前，是否增加信息、行动、兑现或下一步价值。
2. **连续性**：人物动机、时间线、世界规则、前后因果和伏笔是否仍成立。
3. **指标防作弊**：是否只是把流失后移、制造标题党、机械缩短、假悬崖或删掉必要理解信息。

有子 Agent 时可由故事架构/叙事角色审查修改机制，再由一致性检查器审查跨章后果。无子 Agent 时逐项自检，并在报告中写出风险。

### 9.4 单变量实验卡

```markdown

- 原文问题：
- 唯一主要变量：
- 修改后读者新增获得的信息/行动/收益：

- 最小有意义变化及其依据：
- 护栏指标：
- 失败信号：
- 回滚条件：
- 实际上线时间：
- 首个覆盖窗口：
- 主要复盘窗口：
- 并发改动：
```
