# 异动识别、样本与归因规则

> 本文件中的阈值是内部分析默认值，不是番茄官方及格线。平台没有公开统一优秀阈值；应优先用同一本书、同一渠道、同一更新状态下的历史基线校准。

## 1. 证据等级

给报告里的关键句标记证据性质，避免把推测写成事实：

| 标签 | 含义 | 示例 |
|---|---|---|
| `OBSERVED` | raw 或后台直接观测 | 日阅读人数 3，书城 1、搜索 2 |
| `DERIVED` | 能从原始分子/分母复算 | 第1→2章同步到达比 8/25=32% |
| `ASSOCIATION` | 时间或结构上相关，但非因果 | 改文后窗口转化低于改前 |
| `HYPOTHESIS` | 文本机制的待验证解释 | 第二章开头撤回第一章悬念可能劝退 |
| `CAUSAL` | 随机实验或可信准实验支持 | 只有满足严谨对照条件时使用 |

观察性后台数据通常最多到 `ASSOCIATION`。没有随机分组、可信对照或可分离 cohort 时，不要使用“证明是修改导致”。

## 2. 可比数据单元

每次快照至少记录：

```text
pulled_at          拉取时间与时区
data_until         数据统计截止时间
metric_definition  tooltip 原文或定义核验日期
work_id            作品 ID
chapter_id/version 章节和发布版本
period             单日、累计、7日、14日滚动、自定义
channel            渠道
numerator          分子
denominator        分母
displayed_rate     后台展示值
publish/edit_at    发布或修改时间
concurrent_events  断更、复更、换封面、换名、改标签、活动等
```

只有以下条件成立时，才比较业务表现：

- 指标定义、统计周期、作品和章节版本一致；
- 数据截止关系明确；
- `0 / null / 空字符串 / 未出数 / 请求失败`已区分；
- 比率能取得分子与分母，或明确标记为低可信展示值；
- 改动和其他干扰事件已登记；
- 渠道或推荐阶段可比，或已单独拆分。

否则先判数据问题，不解释成内容变化。

## 3. 数据质量异动

### 3.1 直接判为数据不可用于结论

出现任一情况时，标记 `L0 数据异常`：

- `date/data_until` 未达到预期；
- 登录失效、请求参数缺失或接口整页异常归零；
- 部分字段更新、部分字段仍停留在旧快照；
- 同一截止日多次拉取仍改变，平台正在回填；
- 分子大于分母、比例超出 0%–100%；
- 同一快照的章节到达、跟读关系超出可解释的舍入误差；
- 中间章到达为 0、深章有到达，而分析仍假定人人顺序阅读；
- 新章节尚未发布，却被当作 0 跟读归责前章；
- 平台统计范围、去重规则或反作弊口径刚切换。

处理方式：

1. 保存原始值，不覆盖为“修正后的 0”。
2. 标记具体异常字段和可信替代字段。
3. 同一截止日稍后复拉，或打开后台核验 tooltip/页面值。
4. 在数据稳定前只给事实，不给作品优劣判断。

### 3.2 判断平台是否尚未刷新

不要只看 `data_until`。同时检查：

- 当前是否早于平台通常更新时间；
- 最新日值是否整组占位 0；
- 总览字段、趋势字段、章节字段是否同步；
- 同一截止日稍后复拉是否变化；
- 渠道合计是否与阅读人数一致。

若只是一项真实为 0、其他字段已同步，不能因“看起来太低”就判未刷新。

## 4. 历史基线与计数异动

### 4.1 选择基线

优先使用最近 28 个有效、无干预、同星期结构、同更新状态、同主要渠道的观察点：

- 有效点 `≥14`：可建立稳健历史噪声基线；
- 有效点 `7–13`：只做临时提醒；
- 有效点 `<7`：不自动判统计异动，只报告绝对变化。

作品早期、平台测试阶段或流量断续时，优先使用“修改前最后可比快照 + 聚合前后窗口”，不要假装有稳定日常分布。

### 4.2 稳健计数提醒

对阅读、展示、互动等计数 `x`，计算：

```text
m   = 历史可比点中位数
MAD = median(|x - m|)
σr  = 1.4826 × MAD
```

内部提醒条件：

```text
|最新值 - m| > max(3 × σr, 历史日变化绝对值P95, 2人)
```

这是“值得调查”的提醒，不是改善/恶化结论。`MAD=0` 时使用 IQR 或历史经验分布；基数接近 0 时只报绝对人数，不报夸张的相对涨幅。

进入方向判断需额外满足：

- 最近 3 个可比点至少 2 个同向，或聚合后窗口超出基线噪声；
- 变化未被上游展示/阅读量、渠道切换或滚出窗口解释；
- 目标指标和护栏指标没有相互矛盾。

### 4.3 计数的上游依赖

先问计数是否只是分母规模变化：

- 阅读下降、展示同步下降：优先判分发变化；
- 加书架下降、阅读下降更多：绝对数变少不等于书架意愿下降；
- 计数为 0：只有当合格分母明确大于 0 且历史上 0 很罕见时，才构成提醒；
- 14 日总数下降：先检查旧高值滚出，而不是写“今天流失”。

## 5. 比例与漏斗异动

### 5.1 强制展示四件事

有权威分子/分母时，任何比例都同时写：

```text
分子/分母、当前率、绝对人数变化、百分点变化
```

例如（假设两期都是同口径、权威 cohort 计数，不是从展示百分比反推的最小兼容下界）：

```text
改前 7/20=35%，改后 8/25=32%
分母 +5，分子 +1，转化 -3pp
```

正确结论是“绝对进入人数增加 1，但新增入口增长更快，条件转化方向下降”；不能只写“跌了 3 个点”或“多了 1 人所以改善”。

若平台只给展示百分比，则只报告比例和百分点变化，并把分母写为不可得；最小兼容整数下界只能检查单份曲线的一致性，禁止套用上例相减成人数。

### 5.2 区间与效应量

有原始分子/分母时：

- 使用 Wilson 区间或二项精确区间；
- 两组小样本优先用 Fisher 精确检验；
- 大样本可用两比例差的置信区间；
- 报告 `Δpp`、相对变化和区间，不只报 p 值；
- 在看结果前定义最小有意义变化 `MDE`。没有预设 MDE 时，只能说统计上可检测，不能说业务上重要。

### 5.3 样本分层

以下为内部风险护栏：

- 权威分母 `<30`：只报权威人数/率和方向，状态为“样本不足”，不做修改因果归因。最小兼容下界不得用于判定样本层级。
- 分母 `30–99`：只有绝对人数与比例同向，且两个可比窗口同向或聚合效应超过历史噪声，才给方向性判断。
- 分母 `≥100`：结合置信区间、MDE、渠道/版本可比性与护栏，才可能给较强结论。

人数达到阈值不自动等于可信。自访、渠道换血、同批读者重复、版本混读仍会让结论降级。

### 5.4 找最早异常，不重复归因

漏斗中最早显著异常会自然传导到后续。先定位最早异常，再看后续是否还有额外条件转化下降。

优先级同时考虑：

- 条件转化的异常程度；
- 该节点流失的绝对人数；
- 可挽回人数；
- 修改位置与成本；
- 是否在独立后续窗口复现。

扫描很多章节时，“最大跌幅”容易被小样本和多重比较放大。至少要求断点在后续窗口复现；正式统计可使用 Benjamini–Hochberg FDR。没有复现时只列候选断点。

## 6. 累计章节快照

设 `A_n(t)` 为快照 `t` 时累计到达第 n 章的人数。

同一顺序阅读 cohort 理论上应满足：

```text
A_(n+1)(t) ≤ A_n(t)
```

实际存在直达、跳读、旧读者推进、去重校正和字段不同步。发现反常时不要硬套顺序漏斗。

重要限制：

```text
A_n(t1) - A_n(t0)
```

只是两个快照之间该章累计到达的净变化，不等于同一批新读者到达该章。不同读者到章存在时间滞后，旧读者也可能在改文后继续推进。

因此：

- `ΔA2/ΔA1`只能称“窗口增量到达比”；
- 修改前后累计曲线只能给信号，不能当严格 A/B；
- 若平台提供首次阅读日期 × 章节版本 cohort，再计算真正改后转化；
- 百分比反推人数时保留“约等于”和候选误差，不伪造唯一精确分母；
- 下一章未发布或发布窗口极短时，不归责前章。

## 7. 14 日在读滚动窗

相邻两个 14 日窗口共享 13 天，强相关。若 `R_t` 为截至 t 的 14 日在读：

```text
R_t - R_(t-1)
```

不是“今日新增减今日流失”，只能理解为新一日进入与最旧一日滚出共同作用后的净变化，而且用户可能跨日去重。

分析规则：

1. 相邻日 `+1/-1`只作监控事实。
2. 用日阅读序列解释哪一天滚出、哪一天进入，但没有用户级集合时不要给精确新增/流失人数。
3. 趋势比较优先看 `R_t` 与 `R_(t-14)`或完整非重叠窗口。
4. 修改后前 13 天窗口仍混入改前流量；不能据单日滚动值证明改文效果。
5. 不把 14 个滚动值相加，也不把相邻窗口当作独立样本。

## 8. 渠道结构异动

设渠道占比为 `w_c`，渠道内转化为 `p_c`，则总转化由渠道结构与渠道内表现共同决定：

```text
总转化 = Σ(w_c × p_c)
```

总转化变化时依次检查：

1. 各渠道绝对阅读人数；
2. 各渠道占比是否换血；
3. 能否取得渠道内转化；
4. 同一主要渠道内是否也同向变化。

若总转化下降主要因为搜索/推荐等渠道构成改变，只能说“读者结构变化”；主要渠道内部都下降才更支持内容承接变化。

渠道占比异动可用历史 MAD、PSI 或 Jensen–Shannon divergence 监控，阈值取本书历史 P95，不套行业通用线。平台未确认渠道互斥时，这只是结构诊断，不是用户去重分解。

## 9. 修改前后比较

### 9.1 事件卡

每次改动建立：

```text
改动对象与版本：
实际上线时间：
目标读者开始看到新版的时间：
唯一主指标：
护栏指标：
改前窗口：
过渡窗口：
改后窗口：
同时发生的更新/包装/标签/活动：
```

### 9.2 比较规则

- 前后窗口尽量等长，星期结构、更新频率和推荐阶段一致；
- 日数据必须等平台刷新完成后再纳入；
- 首次实际覆盖窗口与首个完整自然日分开；
- 累计章节数据没有版本 cohort 时降级；
- 同时改书名、封面、简介和正文，只能评价整套方案；
- 优先使用未修改章节、相似稳定渠道或平台原生实验作为对照；
- 有可信对照时可用差分中的差分，但需检查改前平行趋势。

较强证据至少需要：

- 效应区间不跨 0；
- 效应超过预先定义的 MDE 或历史噪声 P95；
- 至少两个非重叠 cohort/窗口同向；
- 曝光、渠道、更新、版本等上游没有更强替代解释；
- 护栏指标没有明显恶化。

## 10. 结论状态与强度

| 级别 | 条件 | 允许表述 |
|---|---|---|
| `L0 数据异常` | 刷新、字段、口径或版本不可比 | 本次字段不可用于内容判断 |
| `L1 提醒` | 单日越界、小样本、只有展示比例、滚动窗相邻波动 | 出现上/下行信号，继续观察 |
| `L2 方向` | 有效样本、效应超过自身噪声、重复同向、主要干扰已检查 | 数据支持上升/下降方向，因果仍有限 |
| `L3 较强证据` | 独立窗口/可信对照、区间与MDE通过、护栏稳定、无重大并发干预 | 有较强证据支持改动与改善/恶化一致 |

日报仍使用用户易懂的状态：

`改善 / 恶化 / 无明显变化 / 样本不足 / 数据未覆盖改动 / 样本受自访污染`

并另列：

```text
当前方向：上行 / 下行 / 持平
证据等级：L0 / L1 / L2 / L3
```

没有随机实验或可信准实验时，即使 L3 也使用“强支持、与修改一致”，不要写“已经证明修改造成增长”。

## 11. 强制输出字段

每条重点异动按以下模板记录：

```markdown
### [指标] 异动

- 数据状态：VALID / PARTIAL_REFRESH / BACKFILLING / INVALID
- 证据性质：OBSERVED / DERIVED / ASSOCIATION / HYPOTHESIS / CAUSAL
- 比较口径：定义、截止日、窗口、章节版本、渠道
- 当前值：分子 / 分母 / 比率
- 基线：中位数、MAD/IQR、有效观察数
- 效应：绝对变化、相对变化、百分点、置信区间
- 干扰项：分发、渠道、断更、改稿、自访、平台回填
- 当前方向：上行 / 下行 / 持平
- 结论等级：L0 / L1 / L2 / L3
- 允许结论：
- 禁止结论：
- 下一验证动作：
```
