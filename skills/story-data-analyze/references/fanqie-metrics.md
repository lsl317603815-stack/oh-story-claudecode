## 1. 长篇小说指标

### 1.1 作品与互动指标

| 指标 | 官方口径 | 可以回答 | 不能直接回答 |
|---|---|---|---|
| 阅读人数 | 每日作品产生“听+读”的用户数量 | 当日有多少用户消费作品 | 曝光量、点击率、章节流失位置 |
| 在读人数 | 最近 14 天作品累计“听+读”用户数量；代表近期热度/读者活跃度，与收入关联不大，不同作品不具备比较性 | 本书近期活跃规模的大致趋势 | 历史累计读者、单日新增/流失、前三章分母、跨作品优劣 |
| 加书架人数 | 当日将作品加入书架的读者数，未扣除当日移除书架数 | 当日新增书架动作 | 净增书架、算法权重、读者一定会回访 |
| 催更人数 | 读到最新章后点击催更的读者数 | 到达最新章者中的期待动作 | 所有阅读者的普遍评价；没有到达最新章资格者不能算入同一分母 |
| 追更人数 | 阅读最近 7 日更新章节的有效读者数 | 近期更新被有效阅读的规模 | 泛化的订阅总人数、单章跟读率 |
| 评论次数 | 段评、章评、书评、章末讨论总条数；删除后可能下降 | 互动量与可供质性分析的文本证据 | 唯一读者数、正负情绪；需另读评论内容 |
| 作品评分 | 有一定阅读时间的读者评分；短时或恶意评分不计；更新前后可能变化 | 合格评分者的综合评价 | 当日所有读者满意度、短时实时改文效果 |

处理规则：

- 加书架、催更、追更的资格人群不同，不要统一除以“在读人数”。
- 平台未提供合适资格分母时，只报告绝对数和趋势，最多明确标注“诊断代理比率”，不得冒充官方转化率。
- “继续阅读”属于阅读来源之一，不是全平台跨日回访人数的完整定义。

### 1.2 流量来源

后台展示：`书城 / 分类 / 书架 / 继续阅读 / 搜索 / 其他`。

官方公开页只说明它们是各渠道的读者来源，面积代表各渠道读者数量。没有公开更细的曝光、去重、归因或互斥规则。因此：

- 书城或分类阅读 UV 为 0，只能写“未观察到该渠道带来的阅读 UV”。
- 不得写“平台零曝光”“未通过推荐评估”或“完全没有分发”。
- 书架来源不等于当日新增书架人数。
- 继续阅读为 0 不等于绝对无人跨日回访。
- 搜索占主导时需确认是否存在作者/熟人访问，但确认前不能直接删除全部搜索样本。

若各渠道日值合计与阅读人数一致，可用作本次数据的内部一致性校验；这不证明各渠道在所有场景永久互斥。

### 1.3 章节指标

| 指标 | 官方口径 | 正确解释 |
|---|---|---|
| 章节读完率 N | 读者阅读至第 N 章的比例 | 累计到达第 N 章的比例，不是“打开第 N 章后读完本章的比例” |
| 章节跟读率 N | 阅读了第 N 章后又阅读第 N+1 章的占比 | 第 N 章读者进入下一章的条件转化 |
| 字数读完率 | 作品满 10 万字后新增读者，从第 1 章读至第 N 万字的比例 | 万字粒度的新增读者到达曲线 |

同一 cohort、同一同步快照且无四舍五入时，理论上：

```text
到达率(N+1) = 到达率(N) × 跟读率(N)
```

后台字段可能分批刷新或四舍五入。展示跟读率与到达人数不一致时：

1. 保留原始字段；
2. 有权威到达人数时用同份人数计算同步条件转化；没有时直接用同快照 `到达率(N+1)/到达率(N)`，不得把最小兼容整数下界当真实人数；
3. 标记字段滞后/口径待核实；
4. 不直接照抄不一致的跟读百分比下结论。

章节诊断边界：

- `A(N+1)/A(N)` 指向 N→N+1 的承接，但不能证明问题只在第 N 章最后一句。
- 检查第 N 章全章、章末、下一章标题和下一章开头。
- 扫描大量章节时最大的自然跌幅可能只是小样本噪声，需在后续窗口复现。
- 累计章节曲线混合改前与改后读者；没有章节版本 cohort 时只能做方向性观察。
- 由展示百分比求得的最小兼容整数解只是 cohort 下界，不是人数估计；不可跨快照相减或充当 `<30/≥100` 样本门的分母。

## 2. 短故事指标

### 2.1 官方漏斗

| 节点 | 官方口径 | 主要诊断位置 |
|---|---|---|
| 展示人数 | 作品被展示的总人数 | 分发、题材/标签、平台阶段；不能单凭它诊断正文 |
| 阅读人数 | 作品产生阅读的总人数 | 展示→阅读承接 |
| 点击率 | 展示人群中产生阅读的占比 | 书名、封面、开头导语对外包装 |
| 15 秒阅读人数 | 阅读超过 15 秒，约对应开头前 300 字 | 首屏冲突、人物和题材承诺 |
| 30 秒阅读人数 | 阅读超过 30 秒，约对应开头 500–1000 字 | 目标、对手、核心矛盾和第一轮信息增量 |
| 60 秒阅读人数 | 阅读超过 60 秒，约对应开头 1000–2000 字 | 冲突升级、第一轮兑现/反转、继续阅读理由 |
| 触底人数 | 在番茄系 App 阅读完整本的人数 | 60 秒后的中后段结构、反转、情绪回报与收束 |

固定拆解：

```text
点击率       = 阅读 / 展示
15秒留存     = 15秒 / 阅读
15→30承接率  = 30秒 / 15秒
30→60承接率  = 60秒 / 30秒
60秒后触底率 = 触底 / 60秒
整体触底率   = 触底 / 阅读
```

每级同时计算损失绝对人数。最终触底率低不代表结尾一定有问题；必须先找到最早出现异常的条件转化。

### 2.2 常见组合解释

- 展示低、后续转化不错：先查分发与包装测试机会，不因低展示重写整篇。
- 点击低、15 秒留存高：内容承接尚可，优先改书名/封面/导语，保持与正文一致。
- 点击高、15 秒留存低：包装可能过度承诺或开头没有立即兑现。
- 15 秒高、30/60 秒掉：首钩有效，但目标、阻力、信息增量或第一次兑现不足。
- 60 秒高、触底低：开篇有效，中段推进、反转铺垫、重复桥段或结尾回报有问题。
- 触底高但互动弱：再看情绪余韵、人物共鸣、结尾回收和评论内容，不要倒推为“完读无价值”。

## 3. 周期、累计与刷新口径

短故事官方数据说明：

- `累计`按全周期用户去重，同一人多日阅读只计一次。
- `7/14/30 天/自定义`为每日数据求和，同一人跨日可能重复计入。
- 两类口径不能直接同比或相减成“新增用户”。
- 2025-06-24 起部分短故事指标展示范围改为仅番茄系 App；跨口径切换的升降不能归因于改文。

刷新规则：

- 番茄数据通常在每天中午 12 点及以后更新上一数据日。
- 中午前即使接口末尾已有前一日期，也可能仍是占位值；需结合拉取时间、前后字段是否同步、同日复拉结果判断。
- 同一数据截止日若复拉仍发生变化，标记平台回填，不冻结结论。

## 4. 推荐与改文相关官方事实

- 长篇推荐存在资格、推荐评估与小流量验证阶段；验证期每日阅读数不等同于作品真实质量。
- 展示→阅读主要受封面、书名、简介承接影响。
- 官方建议结合章节读完率、章节跟读率和评论定位明显流失章节。
- 断更签约作品恢复更新后，次日恢复系统推荐；作品状态提示本身不代表换流量池。
- 官方改文建议：先看整体到达曲线与跟读断点；若第 20 章曲线明显下降，应从第 19 章开始检查；小问题做局部修改，大结构问题才动多章；修改后约一周再判断，首日可能受字数变化影响。
- 突然单点断崖优先查毒点、逻辑违和或承诺落空；跳章常见于无信息增量的过渡与配角段落。

## 5. 官方没有公开的内容

以下内容不得伪装成官方规则：

- 书城/分类/搜索等渠道的完整曝光和用户归因算法；
- 推荐算法各指标权重；
- 通用点击率、跟读率、完读率及格线；
- “加书架比读完率更重要”；
- “固定 5000 测试读者”等万能流量池说法；
- 本 Skill 的 `<30 / <100` 样本规则。它们是内部风险护栏。
