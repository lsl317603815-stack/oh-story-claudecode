# 去味模式治理

模式清单是可证伪的编辑假设，不是“真人写作法典”。命中只说明需要看语境，不等于作者一定使用了 AI。

## 三类规则

| 类型 | 处理 | 例子 |
|---|---|---|
| 确定性硬门 | 高置信且边界明确，可 blocking | 未授权英文泄漏、HTML 标记、模型退化截断、项目明确禁止的写法 |
| 表层规则 | 按语料验证规则表执行：只告警并给候选位置，不 blocking、不自动改 | 破折号限量提示、待定句式、预注册赤字（感叹号／问号偏少） |
| 结构假设 | 只允许语义审计，不自动改 | 人物声线趋同、全文节拍同构、反复解释意义 |

语义规则至少包含 `id`、`scope`、`semantic_risk`、`signals`、`exclusions`、`preservation`、`auto_fix` 和 `evidence_status`；表层规则另带 `status`、`R`、`corpus_fingerprint` 与 `version`，可追到产生它的语料统计。两者都在 [模式契约](pattern-contracts.json)：`patterns` 是语义候选，`surface_rules` 是表层规则表。

## 语料验证规则表

表层规则只在 AI 稿出现率显著高于真人稿时成立。现行表 `v1-2026-10-06` 来自三族新模型无约束稿对六本外部热门原文的统计（单基线加严：R ≥ 2.0 纳入，1.25–2.0 需三族与对位题材池同向），由作者 2026-10-06 拍板：

| status | 含义 | 执行 |
|---|---|---|
| `conditional` | 条件成立（仅 L04 破折号） | 章级率超过所在题材池真人 P90 才提示一次，附候选位置 |
| `candidate` | 新候选（W01「猛地」） | 同上，但证据未复验，不计入问题密度 |
| `pending` | 量不足，去留未定 | 维持现状但降为 advisory，只列命中位置 |
| `retired` | 语料淘汰（含旧禁用词一级情态／动作／心理类、「不是A而是B」、对话标签密度、段落与句长均匀、文言比喻词、解释腔表层版） | 检测器仍可跑，默认不输出、不拦截、不计入问题密度 |
| `preregistered_deficit` | 反向指标：AI 用得比真人少（感叹号、问号、叙述问句、口语连接词等） | 低于题材池真人 P10 时提示，不改稿、不加字 |

新一代模型基本不长旧指纹，AI 味更多体现为「少了什么」；把感叹号、问号压得比真人还少，是在把成稿往 AI 一侧推。比喻密度只在 claude／豆包写手族上作族别提示。

阈值按题材池一份：书目录放 `.deslop-thresholds.json`（与 `.deslop-whitelist` 同级）选池、覆盖单条阈值或停用某条提示；找不到时脚本回退 [仓内缺省阈值表](deslop-thresholds.default.json) 的 `default_pool` 并在输出里标注。单书池的阈值等于那本书的文风，作者亲笔正文不足时写 `baseline.source: external`，不冒充本书基线。

## 误杀边界

- 排比可能承担审判感、誓言、口号或人物强迫性思维。
- 重复可能承担创伤回响、线索确认、节奏或人物口头禅。
- 心理直述可能是儿童视角、第一人称自欺或关键认知变化。
- 破折号、碎句和省略可能属于作者稳定文风。
- 对话完整可能来自职业、身份或正式场景，而非声线趋同。

命中排除条件时保留，并在保护账本记录其功能；不要用白名单把整个模式永久关闭。作者把某类写法定为本书文风时（如破折号），在书目录 `.deslop-thresholds.json` 的 `disabled_rules` 停用对应提示，规则表本身不动。

## 模式晋级门

表层规则入表、升档、淘汰只认语料重验证：AI 稿与真人稿各自成池，按上节判据算 R、写手族分组与留出集；新增作者语料或换主力写手模型后手动触发，差异报告由作者拍板后规则表与阈值表一起升版本号。单次命中、GitHub 星数、AI 检测器分数或少量示例都不是证据。

自动改写当前对所有表层规则关闭：脚本只给告警和候选位置，作者或审稿人逐处决定；文件模式的候选稿仍经保真脚本手动应用。语义规则保持 `candidate/advisory`，每个模式须有正例、反例、排除条件、保留说明和改前改后样例，不得破坏剧情事实、人物声线、伏笔或正式文体。
